To enable ARAYA editing for ANY dashboard:

1. Add to allowedPaths in araya-chat.mjs:
   allowedPaths: [..., 'NEW_DASHBOARD.html']

2. Add context to dashboard HTML:
   <div class="araya-chat-container"
        data-dashboard="new_dashboard"
        data-file="NEW_DASHBOARD.html"
        data-can-edit="true">

3. Deploy

→ ARAYA can now edit that dashboard!
