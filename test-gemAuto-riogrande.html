🚀 How to Use

For Production (GitHub Pages):

  • Visit: https://barbrickdesign.github.io/gemAuto.html
  • Page automatically uses local JSON files from /supplier/ directory
  • Displays "Rio Grande" as supplier with accurate pricing

For Local Development (with API):

  1. Install dependencies: npm install
  2. Start backend: node backend/services/riogrande-api-service.js
  3. Serve files: python -m http.server 8000
  4. Visit: http://localhost:8000/gemAuto.html
  5. Check console for: [gemAuto] Rio Grande API success
