Google OAuth 2.0 — Configure GOOG_CLIENT_SECRET
REQUIRED
⚠️ What is GOOG_CLIENT_SECRET? This is the Google OAuth 2.0 Client Secret — a private key that lets your Netlify Functions verify Google sign-in tokens server-side. Without it, Google authentication will silently fail or fall back to unverified client-only flows. Never expose this in browser-side JavaScript.
  • 1
    Open Google Cloud Console

    Navigate to console.cloud.google.com and sign in with the account you want to own the OAuth app (recommend: BarbrickDesign@gmail.com or the designated project account).

  • 2
    Select or Create a Project

    In the top nav, click the project dropdown → "New Project" → name it consciousness-revolution (or select the existing one). Note your Project ID.

  • 3
    Enable Required APIs

    Go to APIs & Services → Library. Search for and Enable:

    • Google Identity Services API (for Sign-In with Google / OAuth 2.0)
    • Gmail API (optional — for GMAIL_CLIENT_SECRET email sending)
    • People API (optional — for profile data)
  • 4
    Configure OAuth Consent Screen

    Go to APIs & Services → OAuth consent screen. Select External, fill in:

    • App name: Consciousness Revolution
    • User support email: your-support-email (e.g. darrickpreble@proton.me)
    • Developer contact: your-developer-email (e.g. BarbrickDesign@gmail.com)
    • Authorized domains: consciousnessrevolution.io · netlify.app

    Add scopes: openid, email, profile. Save and continue.

  • 5
    Create OAuth 2.0 Credentials

    Go to APIs & Services → Credentials → "Create Credentials" → "OAuth client ID".

    • Application type: Web application
    • Name: consciousness-revolution-web
    • Authorized JavaScript origins:
      https://consciousnessrevolution.io
      https://barbrickdesign.github.io
      http://localhost:3000
    • Authorized redirect URIs:
      https://consciousnessrevolution.io/api/auth-login
      https://barbrickdesign.github.io/oauth-callback
      http://localhost:3000/api/auth-login

    Click Create. A dialog will show your credentials:

  • 6
    Copy Your Credentials — Keep Them Safe!
    GOOGLE_CLIENT_ID=xxxxxxxxxx.apps.googleusercontent.com GOOG_CLIENT_SECRET=GOCSPX-xxxxxxxxxxxxxxxxxxxxxxx # These go into Netlify env vars (Step 2) AND GitHub Secrets (Step 3)
    🔒 Security Rule: GOOG_CLIENT_SECRET must ONLY exist as a server-side environment variable (Netlify / GitHub Secrets). Never paste it in any .js, .html, or .json file that gets committed.
  • 7
    Add to Supabase Auth (Google Provider)

    Log into supabase.com/dashboard → your project → Authentication → Providers → Google. Enable and paste GOOGLE_CLIENT_ID + GOOG_CLIENT_SECRET there. This enables server-side token verification through Supabase.

✅ What this unlocks:
  • Google "Sign in with Google" button on login.html, government-grants-portal.html, admin-dashboard.html
  • Secure server-side token verification via netlify/functions/auth-login.mjs
  • Gmail OAuth2 integration for automated emails (with GMAIL_CLIENT_SECRET)
  • User profile data (name, email, avatar) flowing into Supabase user tables

Netlify Environment Variables
REQUIRED
ℹ️ Where to set these Netlify Dashboard → Site → Site configuration → Environment variables (replace site name with your actual Netlify site slug).
  • 1
    Open Netlify Site Environment Variables

    Go to app.netlify.com → Select your site → Site configuration → Environment variables → "Add a variable".

  • 2
    Add Google OAuth Variables (PRIORITY)
    GOOGLE_CLIENT_ID=your-google-client-id.apps.googleusercontent.com GOOG_CLIENT_SECRET=GOCSPX-your-secret-here GMAIL_CLIENT_ID=your-google-client-id.apps.googleusercontent.com GMAIL_CLIENT_SECRET=GOCSPX-your-secret-here GMAIL_REFRESH_TOKEN=1//your-refresh-token-here GMAIL_USER=your-gmail-address@gmail.com
  • 3
    Add Supabase Variables
    SUPABASE_URL=https://your-project.supabase.co SUPABASE_ANON_KEY=eyJhbGciOi... (public anon key) SUPABASE_SERVICE_ROLE_SECRET=eyJhbGciOi... (service role key — KEEP SECRET)

    Find these at supabase.com → Project Settings → API

  • 4
    Trigger a Redeploy

    After adding variables, go to Deploys → "Trigger deploy" → "Deploy site" so the new env vars are picked up by Netlify Functions.

4
Supabase Auth — Enable Google Provider
REQUIRED
  • 1
    Open Supabase Dashboard

    Go to supabase.com/dashboard → select the consciousness-revolution project.

  • 2
    Enable Google Auth Provider

    Navigate to Authentication → Providers → Google. Toggle to Enable. Paste your GOOGLE_CLIENT_ID and GOOG_CLIENT_SECRET. Save.

  • 3
    Set Redirect URL in Google Console

    Back in Google Cloud Console, add this to Authorized Redirect URIs:

    https://your-project.supabase.co/auth/v1/callback

    Find your Supabase URL at: Project Settings → API → Project URL

  • 4
    Set Site URL in Supabase

    In Supabase → Authentication → URL Configuration. Set Site URL to: https://consciousnessrevolution.io. Add redirect URLs:

    https://consciousnessrevolution.io/** https://barbrickdesign.github.io/** http://localhost:3000/**
