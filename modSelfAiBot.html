Project Overview

What You’re Supporting

This project is building a modular, self‑assembling AI robot that can:

  • Understand what capabilities it has—and what it’s missing.
  • Discover and adapt to any compatible module with a shared link standard.
  • Guide a human through precise, step‑by‑step connection instructions.
  • Recommend parts, adapters, and power modules when something is unavailable.

Core build phases your support fuels

  • Link v1 standard – mechanical + electrical interface for all modules.
  • Capability discovery – the robot builds a live “body map” of what’s attached.
  • Guided assembly – detailed instructions when it needs human help.
  • Adaptive sourcing – AI‑generated part suggestions and ordering links.
Example parts your donation may fund
  • Arduino boards, motor drivers, power modules, and protection circuitry.
  • Magnetic/printed link plates, pogo pins, and wiring harnesses.
  • Sensor, drive, and arm modules for capability testing.
  • Adapters (level shifters, step‑up/step‑down converters, protocol bridges).

Robot Needs & Guidance

How the Robot Will Ask for Help

As the system matures, the robot will be able to describe exactly what it needs—missing modules, adapters, or power rails—and generate human‑readable instructions like:

  • "I need a 5V→7.4V step‑up converter for the servo module."
  • "Please connect a drive module to Link Port B using a 4‑pin JST cable."
  • "No distance sensor detected. I recommend adding an HC‑SR04‑compatible module."

Those needs can be translated into part suggestions and ordering links, which you can coordinate and fulfill via the email and donation flow on this page.
