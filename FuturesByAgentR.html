📡 Live Data Setup Guide

Follow these steps to connect live market data to your trading platform:

1
Choose Your Data Provider

Select TopStepX for live futures data or another provider for other markets.

2
Get Your API Credentials

Visit your provider's website to obtain API access:

🏢 TopStepX Dashboard 📊 TradingView 🔷 Polygon.io
3
Start the Data Bridge (TopStepX Only)

For TopStepX users, run the Python bridge server first:

python setup_tsx_api.py --setup && python setup_tsx_api.py --launch

💡 TopStepX is recommended for futures trading with live data. Other providers work for stocks/forex.

Where to find your API Key:

  • TopStepX: Log into your TopStepX dashboard → API Settings → Generate API Key
  • Other Providers: Usually found in Account Settings → API Access or Developer section

⚠️ Keep your API key secure and never share it publicly

API Secret (for non-TopStepX providers):

This is your private key/secret token. Usually found alongside your API key in your provider's dashboard.

🔒 This field is hidden for TopStepX as they only require API Key + Username

Your TopStepX Account Username:

This is the username you use to log into your TopStepX account. Usually your email address or chosen username.

💡 This is the same username you use to log into the TopStepX web platform

🌉 TopStepX API Bridge Configuration

Before connecting, you need to start the Python bridge server:

Step 1: python setup_tsx_api.py --setup

Install dependencies and create configuration

Step 2: python setup_tsx_api.py --launch

Start the live data bridge server

Bridge URL Configuration:

  • Default: ws://localhost:8765 (if running locally)
  • Remote Server: ws://your-server-ip:8765 (if running on another machine)
  • Custom Port: Change 8765 to your chosen port if modified

🔌 Make sure the bridge server is running before testing the connection

Not Connected
🔧 Troubleshooting Tips:
  • Connection Failed: Ensure the Python bridge is running
  • Port Blocked: Check firewall settings for port 8765
  • Wrong URL: Verify the IP address and port number
  • Python Errors: Check the bridge server terminal for error messages
