# 🚀 Developer Onboarding Guide

Welcome to the Consciousness Revolution platform! This guide will help you get started quickly based on your role and interests.

## ⚡ Quick Start (Everyone)

Get up and running in 3 commands:

```bash
npm install           # Install dependencies
npm run onboard       # Auto-generate .env with core variables
npm start             # Start the application!
```

That's it! The automated onboarding creates your `.env` file, generates a unique `UNIVERSE_KEY`, and sets everything up securely.

## 🔐 Security Best Practices

### ✅ DO:
- ✅ Use `.env` for ALL secrets (it's gitignored!)
- ✅ Run `npm run setup:git-hooks` to install pre-commit scanning
- ✅ Use `process.env.VARIABLE_NAME` in code
- ✅ Keep `.env` permissions secure: `chmod 600 .env`
- ✅ Regularly rotate API keys

### ❌ DON'T:
- ❌ NEVER commit secrets to git
- ❌ NEVER hardcode API keys in code
- ❌ NEVER share your `.env` file
- ❌ NEVER commit `.env` (it's gitignored for a reason!)
- ❌ NEVER bypass pre-commit hooks without good reason

### Pre-Commit Secret Scanning

We automatically scan for exposed secrets before each commit:
- OpenAI API keys (`sk-*`)
- GitHub tokens (`ghp_*`, `gho_*`, `ghu_*`)
- Anthropic keys (`sk-ant-*`)
- Groq keys (`gsk_*`)
- AWS credentials
- Database URLs with passwords
- Private keys
- And more...

**Install the hook**:
```bash
npm run setup:git-hooks
```

Now every commit will be automatically scanned. If secrets are found, the commit will be blocked with helpful guidance on how to fix it.

## 🐛 Troubleshooting

### "Permission denied" when running scripts
```bash
chmod +x scripts/*.js
```

### ".env file not found"
```bash
npm run onboard              # Auto-generate .env
```

### "Module not found"
```bash
npm install                  # Install dependencies
cd backend && npm install    # Backend dependencies
```

### "API key not working"
1. Check key format in `.env` (no quotes, no spaces)
2. Restart the application
3. Verify key is valid on provider's dashboard
4. Check rate limits

### Pre-commit hook not running
```bash
npm run setup:git-hooks      # Reinstall hooks
```

### Need to bypass pre-commit hook (NOT recommended)
```bash
git commit --no-verify -m "Your message"
# Only use if you're CERTAIN no secrets are exposed!
```
