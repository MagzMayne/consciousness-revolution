🎯 Testing Instructions

  1. Click "Test AI Vision Mode" to trigger the feature
  2. If html2canvas is not loaded, you'll be prompted to load it
  3. If no API key is configured, you'll be prompted to enter one
  4. Get a free API key from: ai.google.dev
  5. Your API key will be saved for future use (or you can opt out)
  6. Use "View Error Log" to see detailed error information
  7. Use "Clear Stored API Key" to test the prompt again

🔧 Developer Tools

Open browser console (F12) and try these commands:

  • window.RobotAI.activateAIVisionMode() - Trigger AI Vision
  • window.RobotAI.getAIVisionErrorLog() - Get error log
  • window.RobotAI.clearAIVisionErrorLog() - Clear error log
  • window.RobotAI.clearStoredApiKey() - Clear API key
