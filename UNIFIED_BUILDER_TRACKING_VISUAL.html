↓

↓
Writes to BUILDERS table

2️⃣ The Creed Acceptance

↓
User accepts creed → Netlify function
POST /.netlify/functions/araya-creed-accept
↓
Updates BUILDERS table
✅ creed_accepted = true, creed_accepted_at

3️⃣ Contribution Agreement

↓
User signs agreement → Netlify function
POST /.netlify/functions/araya-agreement-submit
↓
Updates BUILDERS table
✅ contribution_agreement = true, contribution_signed_at

4️⃣ Discord XP Sync (Scheduled)

↓
Supabase discord_users_v2 → Netlify scheduled function
CRON /.netlify/functions/discord-xp-sync (*/5 * * * *)
↓
Syncs to BUILDERS table
✅ xp, tier, tier_number, both_platforms = true

5️⃣ 7 Domains Progress

↓
User completes task → Netlify function
POST /.netlify/functions/domain-progress-update
↓
Updates BUILDERS table
✅ domain_1_clarity → domain_7_purpose (%)

6️⃣ Agent R Contributions

↓
Builder submits work → Netlify function
POST /.netlify/functions/araya-contribution-submit
↓
Creates record in CONTRIBUTIONS table
⏳ status = "Pending" → Commander approves

📋 BUILDERS Table Schema (Key Fields)

Field Type Purpose
builder_id Auto Number Primary key
email Email (unique) Universal identifier
discord_user_id Single Line Text Link to Discord XP system
xp Number Synced from Supabase every 5 min
tier Single Select SEED → GUARDIAN (7 tiers)
domain_1_clarity → domain_7_purpose Percent 7 Domains progress (0-100%)
mission_statement Long Text Builder's mission (50+ words)
creed_accepted Checkbox Agreed to principles
contribution_agreement Checkbox Signed unpaid agreement
paid_agreement Checkbox Signed paid agreement + rate
discord_only / web_only / both_platforms Checkbox Platform flags (mutually exclusive)

💼 CONTRIBUTIONS Table Schema

Field Type Purpose
contribution_id Auto Number Primary key
builder_id Link to BUILDERS Who contributed
contribution_type Single Select Code, Design, Content, Bug, Test, Other
description Long Text What they did
hours Number Time spent
value Currency $ amount (if paid)
status Single Select Pending, Approved, Rejected, Paid
github_pr / evidence_url URL Links to proof of work
reviewed_by Single Line Text Commander approval
payment_method Single Select PayPal, Venmo, Cash, Equity, Crypto
