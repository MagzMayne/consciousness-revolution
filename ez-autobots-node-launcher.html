Option A — Desktop launcher (recommended): Download the Starter Pack, unzip, and run start.bat (Windows) or start.sh (macOS/Linux). The script installs Node.js if needed and keeps a local node running in the background.

Option B — Browser node: Scroll to "Register This Browser" and click Register & Start. Your browser tab acts as a lightweight node and sends heartbeats while open.
