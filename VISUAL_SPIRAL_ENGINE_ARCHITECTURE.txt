DATA FLOW - ADD XP EXAMPLE
═══════════════════════════════════════════════════════════════════════════

USER ACTION: Complete mission worth 150 XP
     │
     ▼
FRONTEND: Calls API
     │   POST /.netlify/functions/spiral-progress
     │   Body: {
     │     action: "add_xp",
     │     userId: "user-123",
     │     forgeSlug: "reality",
     │     amount: 150,
     │     source: "mission_complete"
     │   }
     ▼
API: Validates input
     │   ├─ Check userId exists
     │   ├─ Check forge is unlocked
     │   ├─ Check amount > 0
     │   └─ Check source is valid
     ▼
DATABASE: Execute add_xp_and_level_up()
     │   ├─ Get current progress
     │   ├─ Calculate new total_xp (500 + 150 = 650)
     │   ├─ Check level for 650 XP → Level 5 (Adept)
     │   ├─ UPDATE spiral_forge_progress
     │   ├─ INSERT spiral_xp_transactions
     │   └─ IF leveled up:
     │       └─ INSERT spiral_level_ups
     ▼
API: Format response
     │   Return: {
     │     success: true,
     │     data: {
     │       new_level: 5,
     │       total_xp: 650,
     │       leveled_up: true,
     │       amount_added: 150
     │     }
     │   }
     ▼
FRONTEND: Update UI
     │   ├─ Show level-up animation
     │   ├─ Update progress bar
     │   └─ Display new XP total

UNLOCK FLOW - REALITY L7 → ALL FORGES
═══════════════════════════════════════════════════════════════════════════

USER: Reaches Reality Level 7 (Master)
     │   (2,000 total XP in Reality Forge)
     ▼
TRIGGER: add_xp_and_level_up() detects Reality L7
     │
     ▼
FUNCTION: unlock_all_forges(user_id)
     │   FOR EACH forge IN [creation, communications, guardian, wealth, character, infinity]:
     │     ├─ INSERT spiral_forge_progress (level=1, unlocked_at=NOW())
     │     └─ INSERT spiral_forge_unlocks (unlocked_by='reality_l7')
     ▼
RESULT: User now has access to all 7 forges at L1

OCTAVE RETURN - INFINITY L13 → REALITY L8
═══════════════════════════════════════════════════════════════════════════

USER: Reaches Infinity Level 13 (Transcendent)
     │   (37,600 total XP in Infinity Forge)
     ▼
TRIGGER: add_xp_and_level_up() detects Infinity L13
     │
     ▼
FUNCTION: octave_return(user_id)
     │   ├─ GET Reality current level (e.g., L7)
     │   ├─ COUNT previous octave returns
     │   ├─ INSERT spiral_octave_returns (return_count=1, prev_level=7, new_level=8)
     │   ├─ UPDATE spiral_forge_progress SET current_level=8 WHERE forge='reality'
     │   └─ INSERT spiral_level_ups (from_level=7, to_level=8)
     ▼
RESULT: Reality jumps from L7 → L8 (Virtuoso)
     │   User enters "Second Octave" of consciousness spiral
     │   Can now progress through L8-L13 again
