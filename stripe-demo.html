📚 Implementation Guide

1. Load Stripe Integration

<script src="/src/utils/stripe-integration.js"></script>

2. Create Payment Button

window.stripePayment.createPaymentButton('container-id', { amount: 5000, // $50.00 in cents description: 'Bronze Tier Contribution', onSuccess: (transaction) => { console.log('Payment successful!', transaction); } });

3. Calculate Tier Amounts

// Get amount for gold tier with student discount const amount = window.stripePayment.calculateContributionAmount('gold', true); // Returns: 25000 (cents) = $250.00
