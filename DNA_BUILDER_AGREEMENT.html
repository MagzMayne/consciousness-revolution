7. GETTING STARTED

Step 1: Fork and Clone

# Fork the repository on GitHub first, then:
git clone https://github.com/YOUR_USERNAME/consciousness-revolution.git
cd consciousness-revolution

Step 2: Create Your Branch

# Use this naming convention:
git checkout -b team/your-name/feature-description
# Example: team/frances/araya-memory-optimization

Step 3: Get Your Environment

Request your personal .env file from Commander with:

  • Your own DEEPSEEK_API_KEY (free)
  • Your own GROQ_API_KEY (free)
  • SUPABASE_ANON_KEY only (not service role)
  • Your own GITHUB_TOKEN (PAT)

Step 4: Submit Work

git add .
git commit -m "Brief description of changes"
git push origin team/your-name/feature-description

# Then open a PR on GitHub to merge into main
