What is This?

The ARAYA Forge Companion is a floating widget that appears on every forge page, providing contextual access to ARAYA. It adapts its color to match the current forge's chakra energy.

When clicked, it opens ARAYA with full context of which forge the user is working in, enabling more relevant and helpful guidance.

Installation

Add this single line to any forge page:

<script src="/components/araya-companion.js" defer></script>

The widget auto-detects the forge from page meta tags:

<meta name="domain" content="REALITY">
<meta name="forge" content="reality">

Configuration

The widget reads these meta tags:

  • domain - The forge domain (REALITY, CREATION, etc.)
  • forge - The forge slug (reality, creation, etc.)
  • chakra - The chakra name (Root, Sacral, etc.)
  • chakra-color - Override color (optional)

Context Parameters

When clicked, the widget redirects to ARAYA with context:

/araya-chat.html?context=reality&chakra=Root&color=%23FF0000

ARAYA reads these parameters to provide forge-specific guidance.
