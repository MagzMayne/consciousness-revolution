Release Process

  1. Update CURRENT_VERSION in check-update.mjs
  2. Add changelog to VERSION_HISTORY
  3. Update ARAYA_VERSION in araya-chat.html
  4. Deploy: cd 100X_DEPLOYMENT && netlify deploy --prod --dir=.
