1. WHAT IS IT?

Purpose: Multi-layer team communication infrastructure. The Cyclotron Radio is the backbone - external systems send messages IN, internal systems read messages OUT.

Architecture Layers

  • Layer 1: Radio API - Core message routing (radio-in/radio-out)
  • Layer 2: Discord - Community bot, webhooks, team alerts
  • Layer 3: Dashboards - Direct messaging, operator cockpits
  • Layer 4: ARAYA Chat - AI-powered communication

2. RADIO CHANNELS

4. QUICK START

Send a Radio Message (External -> Brain)

# POST to radio-in
curl -X POST https://conciousnessrevolution.io/.netlify/functions/radio-in \
  -H "Content-Type: application/json" \
  -d '{
    "channel": "DISCORD",
    "sender": "my-system",
    "message": "Hello from external system!",
    "priority": "normal"
  }'

Read Radio Messages (Brain -> External)

# GET from radio-out
curl "https://conciousnessrevolution.io/.netlify/functions/radio-out?channel=ARAYA&receiver=my-app"

# Protected channels need auth
curl "https://conciousnessrevolution.io/.netlify/functions/radio-out?channel=COMMANDER" \
  -H "X-Radio-Key: your-key"

Send Discord Notification

// In JavaScript
const response = await fetch(DISCORD_WEBHOOK_URL, {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    content: 'Deployment complete!',
    username: 'Deploy Bot'
  })
});
