┌─────────────────────────────────────────────────────────────────────────┐
│ PROBLEM                                                                 │
└─────────────────────────────────────────────────────────────────────────┘
  ❌ Railway build failing with: "error: undefined variable 'npm'"
  ❌ Nixpacks generating broken Nix expressions
  ❌ Ruby detection despite Node.js project

┌─────────────────────────────────────────────────────────────────────────┐
│ ROOT CAUSE                                                              │
└─────────────────────────────────────────────────────────────────────────┘
  • Invalid package names in nixpacks.toml (nodejs-18_x ≠ nodejs)
  • Unsupported configuration sections in both config files
  • Nixpacks unable to find packages in nixpkgs

┌─────────────────────────────────────────────────────────────────────────┐
│ SOLUTION                                                                │
└─────────────────────────────────────────────────────────────────────────┘

  FILE: nixpacks.toml
  ══════════════════════════════════════════════════════════════════════
  BEFORE (BROKEN):                  AFTER (FIXED):
  ├─ nodejs-18_x ❌                 ├─ nodejs ✅
  ├─ npm ❌ (not found)             ├─ npm ✅
  ├─ [variables] section            ├─ (removed - not supported)
  └─ [phases.build] section         └─ (removed - not needed)

  FILE: railway.toml
  ══════════════════════════════════════════════════════════════════════
  BEFORE (BROKEN):                  AFTER (FIXED):
  ├─ [build.nixpacksPlan] ❌        ├─ (removed - not supported)
  ├─ providers = ["node"]           ├─ buildCommand = "npm ci..." ✅
  └─ No explicit build command      └─ Clear, explicit configuration
