┌─────────────────────────────────────────────────────────────────────────────┐
│ EXAMPLE 1: Commander Edits Dashboard (Instant)                             │
└─────────────────────────────────────────────────────────────────────────────┘

  1. Commander types in ARAYA chat:
     "/edit h1 Welcome Commander"

  2. araya-dashboard-commands.js detects command
     → Extracts: { type: 'edit', selector: 'h1', content: 'Welcome Commander' }

  3. Calls araya-dashboard-edit.mjs with:
     {
       command: "/edit h1 Welcome Commander",
       dashboard_id: "LIFEFORGE_DOMAIN_REMINDER_v1",
       editor_email: "darrickpreble@proton.me"
     }

  4. araya-dashboard-edit.mjs routes to handleEdit()
     → Builds JS: document.querySelector('h1').textContent = 'Welcome Commander'

  5. Calls dashboard-edit.mjs with:
     {
       dashboard_id: "LIFEFORGE_DOMAIN_REMINDER_v1",
       edit_type: "js",
       content: "(function() { ... })();",
       editor_email: "darrickpreble@proton.me",
       commander_bypass: true
     }

  6. dashboard-edit.mjs checks:
     → isCommander() = TRUE
     → Apply INSTANTLY

  7. Writes to dashboard_customizations table:
     {
       dashboard_id: "LIFEFORGE_DOMAIN_REMINDER_v1",
       owner_name: "Commander",
       custom_js: "(function() { ... })();",
       is_active: true
     }

  8. Returns success to ARAYA chat:
     "✅ Edit Applied Instantly - Reload dashboard to see changes"


┌─────────────────────────────────────────────────────────────────────────────┐
│ EXAMPLE 2: Builder Edits Dashboard (Approval Queue)                        │
└─────────────────────────────────────────────────────────────────────────────┘

  1. Builder types in ARAYA chat:
     "/theme forge"

  2. araya-dashboard-commands.js detects command
     → Extracts: { type: 'theme', theme: 'forge' }

  3. Calls araya-dashboard-edit.mjs with:
     {
       command: "/theme forge",
       dashboard_id: "LIFEFORGE_DOMAIN_REMINDER_v1",
       editor_name: "Josh",
       editor_email: "josh@example.com"
     }

  4. araya-dashboard-edit.mjs routes to handleTheme()
     → Builds theme vars: { '--bg': '#1a0a0a', '--accent': '#ff4444', ... }

  5. Calls dashboard-edit.mjs with:
     {
       dashboard_id: "LIFEFORGE_DOMAIN_REMINDER_v1",
       edit_type: "theme",
       content: { ... theme vars ... },
       editor_name: "Josh",
       editor_email: "josh@example.com"
     }

  6. dashboard-edit.mjs checks:
     → isOwner() = FALSE
     → isCommander() = FALSE
     → Create PROPOSAL

  7. Writes to improvement_proposals table:
     {
       dashboard_id: "LIFEFORGE_DOMAIN_REMINDER_v1",
       creator_name: "Josh",
       title: "ARAYA: Theme change to forge",
       css_diff: ":root { ... }",
       status: "pending",
       xp_reward: 50,
       change_type: "SAFE"
     }

  8. Returns to ARAYA chat:
     "📋 Edit Queued for Approval - XP Reward: 50 | Change Type: SAFE"


┌─────────────────────────────────────────────────────────────────────────────┐
│ EXAMPLE 3: Direct Bridge API Call                                          │
└─────────────────────────────────────────────────────────────────────────────┘

  1. Dashboard has araya-editor-bridge.js loaded
     → window.ARAYA_EDITOR available

  2. Script calls API:
     await window.ARAYA_EDITOR.edit('.title', 'Updated Title');

  3. Bridge applies edit locally (instant feedback):
     document.querySelector('.title').textContent = 'Updated Title';

  4. Bridge calls araya-dashboard-edit API:
     Same flow as EXAMPLE 1 or 2 (depending on permissions)

  5. If API succeeds:
     → Edit persisted
     → History logged to localStorage

  6. If API fails:
     → Fallback: Save to localStorage only
     → Returns: { success: true, mode: 'local-only' }

  7. On page reload:
     → Bridge auto-applies localStorage edits
     → Syncs to API when available
