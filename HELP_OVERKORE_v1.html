WHAT IS OVERKORE?
The local power tools. Two components: OVERKORE CLI (command-line interface) and OVERKORE Orchestrator (multi-AI agent coordination). These run on your machine, not in the cloud. Think: local brain, local power.

OVERKORE CLI

Command-line interface for power users. Direct access to local systems.

Example Commands

# Query the brain
overkore brain search "pattern theory"

# Run boot checkup
overkore system check

# Sync with cloud
overkore sync push

# Generate report
overkore report daily

Key Features

  • Brain Queries: Search 166k+ atoms in Cyclotron
  • System Management: Boot, shutdown, health checks
  • File Sync: Push/pull between local and cloud
  • Report Generation: Auto-generate status reports
  • Local Automation: Run Python scripts, batch jobs

OVERKORE ORCHESTRATOR

Multi-AI agent coordination system. Run teams of AI agents locally.

Architecture

                         +-----------------+

                         |   (Ollama)      |
                         +-----------------+

Key Features

  • Multi-Agent Teams: Multiple AI agents working together
  • Task Decomposition: Break complex tasks into steps
  • Local LLM Support: Use Ollama models (no API costs)
  • Framework Support: Built on CrewAI/LangChain
  • Tool Integration: Agents can use tools (search, write, etc.)
