  1. Look for the 🤖💬 floating button in the bottom-right corner of the page

🔧 Integration Details

The R3-D3 Agent Communication system connects to the AUL (AI Universal Language) protocol:

API Endpoints (when available):
• GET http://localhost:8766/api/agents - List all agents
• GET http://localhost:8766/api/stats - System statistics
• GET http://localhost:8766/api/messages - Message stream
• GET http://localhost:8766/api/health - System health

Current Mode: Mock Data
The panel displays simulated data for demonstration. Start the AUL Dashboard API to connect to real agents.

🚀 Getting Started

To use with real autonomous agents:

  1. Start the AUL Dashboard API:
    python3 aul_dashboard_api.py
  2. Start the AUL Orchestrator:
    python3 aul_orchestrator.py
  3. Deploy autonomous agents (they will auto-register)
  4. Change useMockData: false in robot-aul-connector.js
  5. Open any page with R3-D3 and view live agent data
