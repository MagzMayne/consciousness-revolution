🤖 For Bot Developers

To integrate with your Discord bot, parse the HTML and extract metadata:

// Example: Fetch and parse r3Link.html
const response = await fetch('https://barbrickdesign.github.io/r3link.html');
const html = await response.text();

// Extract meta tags
const repoUrl = html.match(/<meta property="repository:url" content="([^"]+)"/)?.[1];
const projectsUrl = html.match(/<meta property="repository:projects" content="([^"]+)"/)?.[1];
const discordUrl = html.match(/<meta property="discord:server" content="([^"]+)"/)?.[1];

// Fetch projects
const projects = await fetch(projectsUrl).then(r => r.json());
console.log(`Found ${projects.meta.total_items} projects!`);
