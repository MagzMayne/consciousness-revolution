✨ What is AI Vision Mode?

AI Vision Mode is R3-D3's newest feature that uses Google Gemini's computer vision capabilities to analyze web pages. It can identify elements, understand page structure, and provide intelligent suggestions.

  • 📸 Automatic Screenshot Capture - Captures the current page state
  • 🧠 AI-Powered Analysis - Uses Gemini 2.0 Flash for fast processing
  • 🔍 Smart Element Detection - Identifies interactive elements with confidence scores
  • 💡 Contextual Suggestions - Provides actionable recommendations
  • 🛡️ Privacy First - No screenshots stored, processed in real-time

🎯 How to Test AI Vision Mode

  1. Look for R3-D3 robot in the bottom-left corner of the screen
  2. Click on R3-D3 to open the menu
  3. Select 🎯 AI Vision Mode from the menu
  4. Wait 3-5 seconds for the analysis to complete
  5. Review the AI's findings:
    • Page summary and understanding
    • Detected interactive elements
    • Smart suggestions for actions
    • AI insights about the page
  6. Close the results and try on different pages!

🔧 Technical Details

API: Google Gemini 2.0 Flash Exp

Screenshot Library: html2canvas (loaded automatically)

Endpoint: /.netlify/functions/gemini-screen-control

Processing Time: 3-5 seconds average

Privacy: Screenshots processed server-side, not stored

🐛 Troubleshooting

If AI Vision Mode doesn't work:

  • Check that GEMINI_API_KEY is configured in environment variables
  • Open browser console (F12) to check for error messages
  • Verify the page has loaded completely before activating
  • Try refreshing the page and running again
  • Ensure you have a stable internet connection

💬 Programmatic Access

You can also trigger AI Vision Mode programmatically:

window.RobotAI.activateAIVisionMode();

Open your browser console and try it!
