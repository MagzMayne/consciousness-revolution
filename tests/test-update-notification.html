✨ Update Notification System Test

What is this?

This page demonstrates the Update Notification System that has been added to all HTML pages in the barbrickdesign.github.io repository.

When you load this page, you should see a notification banner at the top showing:

  • The date and time of the last update
  • Who made the update (from Git commit author)
  • A description of what was changed (from Git commit message)
  • A version number (if present in the commit message)

Features

  • ✅ Automatically extracts Git commit information
  • ✅ Shows update notification on page load
  • ✅ Auto-hides after 8 seconds
  • ✅ Can be manually closed with the ✕ button
  • ✅ Only shows once per version (uses localStorage)
  • ✅ Responsive design works on mobile and desktop
  • ✅ Consistent styling across all pages

How It Works

The system consists of two main JavaScript files:

  1. update-notification-system.js - Core functionality for creating and displaying the notification banner
  2. update-helper.js - Helper that automatically reads Git metadata from page meta tags and initializes the system

When adding this to HTML files, the Python script add-update-notifications.py automatically extracts Git commit information and adds it as meta tags in the HTML head.
