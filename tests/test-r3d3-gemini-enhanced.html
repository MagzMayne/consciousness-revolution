📚 How to Use

  1. Setup: Enter your Gemini API key and click "Test API Key" to verify it works
  2. Real-Time Editing: Type in the text area and click "Start Real-Time Suggestions" to get AI assistance as you write
  3. Streaming: Enter a prompt and watch the AI response stream in word-by-word
  4. Vision: Test advanced vision features like accessibility analysis and component detection
  5. Save Key: Your API key is stored locally in your browser for convenience

📖 API Reference

Creating a Client

const client = window.GeminiEnhanced.createClient(apiKey);

Real-Time Editor

const editor = window.GeminiEnhanced.createEditor(client);
const sessionId = await editor.startEditingSession('#my-textarea');

Streaming Content

for await (const chunk of client.streamContent({ text: prompt })) {
  console.log(chunk);
}

Vision Analysis

const analyzer = window.GeminiEnhanced.createVisionAnalyzer(client);
const results = await analyzer.analyzeAccessibility(screenshot);
