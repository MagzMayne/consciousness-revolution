## Editing Flow Sequence

```
User Action: await RobotAssistantLoader.editPage('homepage', 'change bg to blue')
    ↓
┌─────────────────────────────────────────────────────────────┐
│ Step 1: Validation                                           │
│ - Check if canEditPages === true                            │
│ - If false, show error and return                           │
└─────────────────────────────────────────────────────────────┘
    ↓
┌─────────────────────────────────────────────────────────────┐
│ Step 2: UI Feedback                                          │
│ - Set isEditing = true                                       │
│ - Set animationState = 'editing'                            │
│ - Show notification: "Analyzing edit request..."            │
└─────────────────────────────────────────────────────────────┘
    ↓
┌─────────────────────────────────────────────────────────────┐
│ Step 3: API Call to ARAYA Bridge                            │
│                                                              │
│ POST http://localhost:5002/edit                             │
│ {                                                            │
│   "user_message": "change bg to blue",                      │
│   "file_path": "homepage"                                   │
│ }                                                            │
└─────────────────────────────────────────────────────────────┘
    ↓
┌─────────────────────────────────────────────────────────────┐
│ Step 4: ARAYA Bridge Processing                             │
│ - Resolve "homepage" → "index.html"                         │
│ - Call Claude API to parse intent                           │
│ - Claude returns:                                            │
│   {                                                          │
│     "action": "edit",                                       │
│     "file_path": "index.html",                              │
│     "old_string": "background: white",                      │
│     "new_string": "background: blue",                       │
│     "reasoning": "Change bg color to blue"                  │
│   }                                                          │
└─────────────────────────────────────────────────────────────┘
    ↓
┌─────────────────────────────────────────────────────────────┐
│ Step 5: File Writer Execution                               │
│ - ARAYA Bridge calls File Writer                            │
│ - POST http://localhost:5001/edit-file                      │
│ - File Writer validates path                                │
│ - File Writer performs string replacement                   │
│ - Returns success/failure                                   │
└─────────────────────────────────────────────────────────────┘
    ↓
┌─────────────────────────────────────────────────────────────┐
│ Step 6: Response Handling                                    │
│                                                              │
│ Success Path:                                                │
│ - Show green notification: "✅ Edit successful!"            │
│ - Set isEditing = false                                     │
│ - Return {success: true, result: {...}}                     │
│                                                              │
│ Error Path:                                                  │
│ - Show red notification: "❌ [error message]"               │
│ - Set isEditing = false                                     │
│ - Return {success: false, error: "..."}                     │
└─────────────────────────────────────────────────────────────┘
```

## Security Architecture

```
┌─────────────────────────────────────────────────────────────────┐
│                     Security Layers                              │
│                                                                  │
│  Layer 1: Frontend (R3-D3)                                      │
│  ├─ Editing disabled by default                                 │
│  ├─ Must explicitly enable with enableAutonomousEditing(true)   │
│  └─ No direct file system access                                │
│                                                                  │
│  Layer 2: ARAYA Bridge                                          │
│  ├─ Validates request format                                    │
│  ├─ Requires Claude API key                                     │
│  └─ Only accepts localhost connections                          │
│                                                                  │
│  Layer 3: ARAYA File Writer                                     │
│  ├─ Domain whitelist enforcement                                │
│  ├─ Path traversal prevention                                   │
│  ├─ File extension validation                                   │
│  ├─ Realpath resolution checks                                  │
│  └─ Only accepts localhost connections                          │
│                                                                  │
│  Layer 4: Operating System                                      │
│  └─ Standard file system permissions                            │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘
```

## API Communication Protocol

### Enable Editing
```
User ──> RobotAssistantLoader.enableAutonomousEditing(true)
         │
         └──> RobotAssistant.enableAutonomousEditing(true)
              │
              ├──> state.canEditPages = true
              ├──> saveState()
              └──> showNotification("Editing enabled", "success")
```

### Edit Page
```
User ──> RobotAssistantLoader.editPage('homepage', 'make bg blue')
         │
         └──> RobotAssistant.editPage('homepage', 'make bg blue')
              │
              ├──> Validate: canEditPages === true?
              │    If false: return error
              │
              ├──> state.isEditing = true
              ├──> setAnimationState('editing')
              │
              ├──> fetch('http://localhost:5002/edit', {
              │      method: 'POST',
              │      body: JSON.stringify({
              │        user_message: 'make bg blue',
              │        file_path: 'homepage'
              │      })
              │    })
              │
              └──> Handle response:
                   ├─ Success: showNotification(green)
                   └─ Error: showNotification(red)
```
