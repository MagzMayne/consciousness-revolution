Component 1: WAKE WORD DETECTION

What it does: Listens constantly for a trigger phrase ("Hey Commander")

Best Open Source: OpenWakeWord BEST FREE

  • GitHub: github.com/dscripka/openWakeWord
  • Install: pip install openwakeword
  • Pre-trained: "alexa", "hey mycroft", "hey jarvis", "hey rhasspy"
  • Custom wake words trainable in <1 hour
  • ~80ms response time

Component 2: SPEECH-TO-TEXT (STT)

What it does: Converts your voice into text

Best Open Source: OpenAI Whisper BEST FREE

  • Install: pip install openai-whisper
  • Models: tiny (fast) -> large (accurate)
  • Runs 100% offline
  • Handles accents, noise, multiple languages

Component 3: BRAIN / AI UNDERSTANDING

What it does: Understands what you want and decides what to do

  • Claude API - Most capable
  • OpenAI API - Very good
  • Local LLM (Ollama) - ollama run llama3 - 100% offline, private

Component 4: TEXT-TO-SPEECH (TTS)

What it does: Speaks the response back to you

Best Open Source: Coqui TTS BEST FREE

  • Install: pip install TTS
  • Natural sounding voices
  • Runs offline

Alternative: pyttsx3 (Simplest)

pip install pyttsx3

Web Speech API (Browser):

function speak(text) {
    const utterance = new SpeechSynthesisUtterance(text);
    speechSynthesis.speak(utterance);
}
speak("Hello Tiger, I'm ready to help!");

Component 5: DESKTOP CONTROL

What it does: Actually performs actions on your computer

  • pyautogui - Mouse/keyboard control
  • subprocess - Run commands
  • os - File operations
  • webbrowser - Open URLs
