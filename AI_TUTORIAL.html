2
PowerShell Setup ~5 minutes

⚠️ The Tricky Part

Windows blocks scripts by default for security. You need to allow them to run Claude properly. This is a ONE-TIME setup.

🔧 Action: Enable Script Execution

  1. Open PowerShell as Administrator (right-click → Run as Administrator)
  2. Run this command:
# Allow scripts to run (one-time setup) Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
  1. Type Y and press Enter to confirm
  2. Now you can run Claude from any terminal

🔑 Action: Set Your API Key

# Set your Anthropic API key $env:ANTHROPIC_API_KEY = "your-api-key-here" # To make it permanent, add to your profile: notepad $PROFILE

Get your API key from console.anthropic.com

  • PowerShell opened as Administrator
  • Execution policy set
  • API key configured

3
Your First Conversation ~15 minutes

Why This Matters

Your first conversation sets the foundation. The AI learns your style, your business, your goals. Think of it as a first meeting with a new team member who has perfect memory.

🚀 Action: Start Claude

# Navigate to your work folder cd C:\Users\YourName\Documents\MyBusiness # Start Claude claude

Example First Conversation

YOU
Hi Claude, I run a small landscaping business. I have client lists in Excel, invoices scattered everywhere, and I'm drowning in scheduling. Help me get organized.
CLAUDE
I can absolutely help you get organized. Let me understand what we're working with. Can you show me:

1. Where your Excel files are located 2. Where invoices are currently stored 3. What tools you use for scheduling

I can look at your folder structure right now if you'd like. Just tell me the main folder where your business files live.
YOU
Everything's in C:\Business - it's a mess though.
CLAUDE
Let me take a look...

[Claude scans your folder and provides organized recommendations]
  • Started Claude successfully
  • Introduced yourself and your business
  • Showed Claude where your files are

4
Recursive Conversations Ongoing

🔄 THIS IS WHERE REAL PROGRESS HAPPENS

One conversation is helpful. Multiple conversations building on each other is TRANSFORMATIVE. Each session compounds on the last. The AI remembers context, builds on previous work, and your progress accelerates exponentially.

The Recursive Pattern

Session 1: "Help me organize my files" ↓ Session 2: "Now let's automate my invoicing" ↓ Session 3: "Build me a client tracking system" ↓ Session 4: "Connect everything together" ↓ Session N: Your business runs itself

Keys to Recursive Success

  • End each session with a summary - Ask Claude to summarize what was done
  • Start next session with context - Reference the previous work
  • Build, don't restart - Each session adds to the foundation
  • Save your conversations - They become your documentation

6
Create Boot Protocols ~30 minutes

Why This Matters

A boot protocol lets you start each AI session with full context instantly. Instead of re-explaining your business every time, you load your protocol and pick up exactly where you left off.

📝 Action: Create Your Boot File

Create a file called BOOT.md in your main folder:

# MY BUSINESS BOOT PROTOCOL ## WHO I AM - Name: [Your name] - Business: [Your business] - Location: [City/Region] ## WHAT I DO [2-3 sentences about your business] ## CURRENT PRIORITIES 1. [Priority 1] 2. [Priority 2] 3. [Priority 3] ## WHERE THINGS ARE - Client files: C:\Business\2_CLIENTS\ - Finances: C:\Business\3_FINANCES\ - Current projects: C:\Business\4_PROJECTS\ ## LAST SESSION [Summary of what we worked on last time] ## TODAY'S FOCUS [What we're working on this session]

How to Use Your Boot Protocol

YOU (at start of each session)
Read my boot protocol at C:\Business\BOOT.md and let's continue where we left off.
CLAUDE
[Reads your boot file]

Got it! I see you're [Your Name] running [Your Business]. Last session we worked on [Previous Work]. Today's focus is [Today's Priority]. Ready to continue!
