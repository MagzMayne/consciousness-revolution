DNA: Autonomous Social Media

Instagram, Discord, and Content Automation

PROJECT DNA
Category: AUTOMATION
STATUS: LIVE

1. WHAT IS IT?

Purpose: Automated social media presence across Instagram and Discord. Autonomous posting, engagement, community management, and content intake.

Capabilities

  • Instagram: Post photos/reels/carousels, auto-engagement, DM automation, story posting
  • Discord: Community bot (ARAYA), verification system, rank progression, task tracking
  • Content Intake: Auto-post from Google Drive folder
  • Analytics: All actions logged to Cyclotron Brain

2. KEY FILES

Instagram Automation

File Purpose
.consciousness/INSTAGRAM_BOT.py Full browser automation (Playwright) - posts, stories, engagement, DMs
.consciousness/INSTAGRAM_CONNECTOR.py Official Meta Graph API - cleaner posting, token management
.social_media_automation/INSTAGRAM_VIDEO_SCRAPER.py Download saved posts, reels, stories with Instaloader
.social_media_automation/INSTAGRAM_DM_SCRAPER.py Read-only DM contact extraction
.social_media_automation/EXPORT_INSTAGRAM_SESSION.py Extract Chrome cookies for session reuse

Discord Automation

File Purpose
.social_media_automation/ARAYA_DISCORD_BOT.py Community gatekeeper, verification, @ARAYA responses
.social_media_automation/ARAYA_DISCORD_BOT_V2.py Enhanced: rank progression, task claims, leaderboards
.consciousness/discord_deploy/ Additional Discord listener and verification systems

Configuration

File Purpose
.env.instagram Instagram API credentials
.env.discord Discord bot token and guild IDs
.secrets/instagram_keys.json Meta API tokens (long-lived)

3. QUICK START

Instagram Bot (Browser Automation)

# Install dependencies
pip install playwright instaloader

# First run - will save credentials
python .consciousness/INSTAGRAM_BOT.py

# Commands:
# - post <image_path> <caption>
# - story <image_path>
# - engage <username> (like + comment)
# - feed_engage (engage on home feed)
# - dm <username> <message>
# - scrape <username> (get profile data)

Instagram Connector (Official API)

# First time setup
python .consciousness/INSTAGRAM_CONNECTOR.py setup

# Post a photo
python .consciousness/INSTAGRAM_CONNECTOR.py photo <image_url> "Caption here"

# Post a reel
python .consciousness/INSTAGRAM_CONNECTOR.py reel <video_url> "Caption"

# Refresh token (do every 60 days)
python .consciousness/INSTAGRAM_CONNECTOR.py refresh-token

Discord Bot

# Install
pip install discord.py python-dotenv

# Run bot
python .social_media_automation/ARAYA_DISCORD_BOT_V2.py

# Features auto-enabled:
# - @ARAYA mentions get AI responses
# - New members go through verification
# - Task claims track in Cyclotron database
# - Leaderboards update automatically

5. RATE LIMITS & SAFETY

Platform Limit Safety Measures
Instagram API 25 posts/24h (standard) Token refresh every 60 days
Instagram Bot Varies (browser) Randomized delays, human-like behavior
Discord 50 msgs/sec Built-in rate limiting

Warning: Instagram browser automation can trigger account restrictions. Use the official API (INSTAGRAM_CONNECTOR.py) for safer posting.
