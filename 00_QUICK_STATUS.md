## 🔧 TROUBLESHOOTING

### Site Not Loading?
- Clear browser cache
- Check browser console (F12)
- Verify all JS files present

### Admin Dashboard Issues?
- Login: `barbrickdesign@gmail.com`
- Check gemBotAdminAPI is loaded
- Verify localStorage has data

### 3D Not Showing?
- Check browser supports WebGL
- Look for console errors
- Verify GLB models exist in models/ folder

### Universe Key Not Working?
- KEY_ID.json must be present
- Check localStorage for previous data
- Test in TEST_UNIVERSE_KEY.html first
