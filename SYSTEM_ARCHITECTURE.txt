  DATA FLOW & STATE MANAGEMENT
───────────────────────────────────────────────────────────────────────────────

┌─────────────────────────────────────────────────────────────────────────────┐
│  USER AUTHENTICATION & STATE                                                 │
├─────────────────────────────────────────────────────────────────────────────┤
│  1. User Email:                                                              │
│     • Source 1: URL parameter (?email=user@example.com)                      │
│     • Source 2: localStorage.getItem('userEmail')                            │
│     • Fallback: Prompt user for email, store in localStorage                │
│                                                                              │
│  2. Progress Tracking:                                                       │
│     • API: GET /api/forge/progress-get?email={email}                         │
│     • Returns: { level, xp, xp_to_next, total_xp, completed_levels }        │
│     • Timeout: 3 seconds                                                     │
│     • Fallback: localStorage OR demo data                                    │
│                                                                              │
│  3. XP Updates:                                                              │
│     • Local: Update localStorage immediately (instant feedback)              │
│     • API: POST /api/forge/xp-add { email, xp_amount }                       │
│     • Returns: { new_total_xp, level_up: boolean }                           │
│     • On level_up: Show level-up overlay animation                           │
│                                                                              │
│  4. Cross-Page Sync:                                                         │
│     • All pages check localStorage on load                                   │
│     • Progress widget polls API every page load                              │
│     • Email persists via URL params + localStorage                           │
