🚀 TopStep Hub Demo

Multi-Account Management & Copy Trading System

📋 Quick Start Guide

  1. Create Accounts
    Start by creating multiple TopStep trading accounts in the Hub. You can create demo, combine, or funded account types.
  2. Set Up Master Trader
    Designate one or more accounts as "Master Traders" to share their signals with other accounts.
  3. Enable Copy Trading
    Configure follower accounts to copy signals from master traders with custom copy ratios and filters.
  4. Start Trading
    Open the futures trading interface for any account and watch signals automatically distribute to followers!

✨ Key Features

📊
Multi-Account Management - Create and manage unlimited TopStep accounts from one central hub
🔄
Copy Trading Engine - Automatically replicate successful trading signals across multiple accounts
📈
Performance Tracking - Real-time metrics including win rate, profit factor, and Sharpe ratio
🎯
Signal Distribution - ML-powered signals (RSI, MA crossover, momentum) shared instantly
⚙️
Customizable Settings - Configure copy ratios, contract filters, and risk management per account
🏆
Leaderboard - Track and compare performance across all your accounts

🎯 Demo Scenarios

Scenario 1: Single Trader

Test the basic trading interface with one account. Create a demo account and explore the futures trading signals.

Scenario 2: Master & Follower

Create two accounts. Make one a master trader and set the other to follow. Watch signals propagate automatically.

Scenario 3: Portfolio Manager

Create 5+ accounts with different risk profiles. One master account distributes signals to all with custom copy ratios.

🔧 Technical Details

💡 How It Works:
  • Hub stores all accounts in localStorage with unique IDs
  • Trading interface loads active account via URL parameter or localStorage
  • Signals generated every 30 seconds based on technical indicators
  • Master traders automatically distribute signals to followers
  • Copy ratios and filters apply to each follower relationship

Key Components:

  • src/topstep/account-manager.js - Account CRUD and performance tracking
  • src/topstep/copy-trading.js - Signal distribution engine
  • src/topstep/hub-integration.js - Trading interface bridge
  • topstep-hub.html - Main hub interface
  • futures.html - Trading interface with hub integration
⚠️ Note: This is a demonstration system using simulated data. For production use with real TopStep accounts, you would need to integrate with actual TopStep APIs and implement proper authentication, encryption, and security measures.
