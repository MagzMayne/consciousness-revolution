🛡️ AI Content Filter - Mobile Bundle

Easy-to-use tool for filtering AI-generated images and videos on mobile browsers. Tag or hide AI content with a simple bookmarklet.

📱 Quick Start:

1Choose your filter settings below

2Tap "Show Bookmarklet" and save it as a bookmark

3Visit any website and tap your bookmark to activate the filter

Filter Settings

Tag: Shows AI content with a visible label | Hide: Replaces AI content with a placeholder

Permissive: Minimal filtering | Moderate: Balanced | Strict: Maximum filtering

Your Bookmarklet


    

    
How to use:

    
1. Create a new bookmark in your browser

    
2. Name it "AI Filter" (or anything you like)

    
3. Copy the code above and paste it as the bookmark URL

    
4. Visit any website and tap the bookmark to activate filtering

    
Note: Some browsers may block bookmarklets due to security policies. If this happens, use the "Test on This Page" button instead.

  


  

    
How It Works

    
This filter analyzes images and videos on web pages to detect AI-generated content. It checks for:

    
    
      
  • Metadata hints (EXIF data, content credentials)
    • 
      
  • Text descriptions mentioning AI tools (Midjourney, DALL-E, Stable Diffusion, etc.)
    • 
      
  • File headers with AI generation markers
    • 
      
  • Context clues from surrounding text
    • 
    

    
Privacy: All processing happens in your browser. No images or data are uploaded to any server.
