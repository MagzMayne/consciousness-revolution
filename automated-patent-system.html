🚀 Quick Start

How to Use This System

This system automatically generates provisional patent applications to protect all ideas created by Ryan Barbrick. Run these commands in your terminal:

# Generate patents for all projects
npm run patent:scan
# Generate patent for specific idea
npm run patent:idea "Your Idea Title"
# List all registered patents
npm run patent:list

⚡ Actions

📝 Generate New Patent

To generate a patent, run the following command in your terminal with your idea title:

npm run patent:idea "Your Amazing Idea Title Here"

Or use the Node.js command directly:

node generate-patents.js --idea "Your Amazing Idea Title Here"
