# Security Policy

## Scope of This Repository

This repository is an **educational and defensive security research archive** of a publicly exposed Claude Code source snapshot. It is maintained by a university student for research purposes.

**This repository is not operated by Anthropic.**

---

## Responsible Use

The source code in this archive originated from Anthropic. If you discover:

- Security vulnerabilities in Claude Code or Anthropic's services
- Leaked credentials, API keys, or secrets embedded in the snapshot
- PII or sensitive user data

**Please report these to Anthropic directly**, not to this repository:

- Anthropic Security: [security@anthropic.com](mailto:security@anthropic.com)
- Anthropic Security Disclosure Policy: [https://anthropic.com/security](https://anthropic.com/security)

---

## Reporting Issues With This Repository

If you believe this repository violates GitHub's Terms of Service, Anthropic's intellectual property rights, or applicable law, please use GitHub's standard reporting mechanisms or contact the repository maintainer.

---

## Research Ethics

Contributors and users of this archive agree to:

1. Use the code exclusively for **defensive security research and education**
2. Not use findings from this archive to attack, compromise, or degrade Anthropic's services or users
3. Not redistribute this code in whole or in part for commercial purposes
4. Responsibly disclose any security issues found to Anthropic before publishing

This archive is provided **as-is** for research purposes. No warranty is made about the accuracy, completeness, or currency of the source snapshot.
