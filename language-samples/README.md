## 🔍 GitHub Language Detection

GitHub uses [Linguist](https://github.com/github/linguist) to detect languages in repositories. This collection ensures maximum language diversity is displayed in the repository statistics bar.

### How It Works

1. GitHub scans all files in the repository
2. File extensions are matched to programming languages
3. Lines of code are counted for each language
4. Repository language statistics are calculated
5. Languages appear in the repository's language bar
