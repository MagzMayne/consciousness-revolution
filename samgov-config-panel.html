🔒 Server-Managed API Key

The SAM.gov API key is stored as a repository secret (SAM_API_KEY) and loaded server-side via /api/sam-gov-token. It is never stored in localStorage or committed to the repo.

To update the key: set the SAM_API_KEY secret in the Netlify dashboard or GitHub repository settings.
