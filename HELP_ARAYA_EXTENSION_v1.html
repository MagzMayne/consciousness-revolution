WHAT IS ARAYA HUD?
Chrome/Brave browser extension that combines 7-domain life organization + AI code capture. Captures code blocks from Claude, ChatGPT, DeepSeek, Gemini, and Copilot. Optional native messaging connects to local Cyclotron brain (166K+ atoms).

INSTALLATION

  1. Open Chrome/Brave → chrome://extensions
  2. Enable "Developer mode" (top right)
  3. Click "Load unpacked"
  4. Select the ARAYA_HUD folder from 100X_DEPLOYMENT

CURRENT PROBLEMS

1. Native Messaging Setup Complex

Connecting to local brain requires:

  • Installing OVERKORE locally
  • Registering native messaging host
  • No automatic installer yet

Currently: Extension works standalone (Cloud Mode) without local connection.

2. Side Panel Chat Not Connected

The sidebar shows ARAYA chat interface but:

  • Doesn't connect to actual ARAYA API yet
  • Should use same backend as araya-chat.html
  • Needs authentication flow
3. Domain Organization UI Incomplete

Captured content should:

  • Be viewable by domain
  • Sync across devices (via Supabase)
  • Export to local files

HOW TO HELP

Option A: Test Code Capture

  1. Install the extension (instructions above)
  2. Go to Claude.ai or ChatGPT
  3. Find a code block in a conversation
  4. Click the capture button that appears
  5. Report if it saves correctly

Option B: Connect Sidebar to ARAYA API

  1. Open sidepanel/araya-sidebar.js
  2. Add fetch calls to /.netlify/functions/araya-chat
  3. Test that conversations work in sidebar

Option C: Create Installer Script

  1. Write a batch/bash script that:
  2. Registers native messaging host
  3. Sets up connection to Cyclotron
  4. Works on Windows/Mac/Linux

TECH STACK

  • Manifest: V3 (Chrome extension)
  • Content Scripts: Vanilla JS
  • Background: Service Worker (ES modules)
  • Storage: chrome.storage.local
  • Native Messaging: Python host (optional)
