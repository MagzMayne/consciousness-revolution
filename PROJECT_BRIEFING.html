How To Make Changes (Without Breaking Things)

  • 1
    ADDITIVE ONLY - Add new code, don't remove existing. Append scripts at end of files.
  • 2
    WIDGET PATTERN - Put new features in /js/ as standalone files. Load them via script tags.
  • 3
    TEST LOCALLY - Open the HTML file in browser before pushing. Check console for errors.
  • 4
    COMMIT OFTEN - Small commits with clear messages. Easy to rollback if needed.
  • 5
    ASK FIRST - Unsure about a change? Post in Discord or message the Commander.
