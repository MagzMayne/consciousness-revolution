## DNA TEMPLATE

Each DNA follows this structure:
1. **WHAT IS IT** - One paragraph summary
2. **STATUS** - Working/Partial/Designed + last tested + issues
3. **LOCATION** - File paths with ~ as home directory
4. **HOW IT WORKS** - ASCII diagram + core logic
5. **KEY FILES BREAKDOWN** - Top 3-5 files explained
6. **DEPENDENCIES** - Required services/libraries
7. **HOW TO RUN** - Quick start commands
8. **HOW TO BUILD** - Build instructions
9. **HOW TO DEPLOY** - Deployment commands
10. **CRITICAL KNOWLEDGE** - Tables, quirks, issues
11. **CONFIGURATION** - Key settings
12. **API REFERENCE** - Key endpoints/functions
13. **EXAMPLES** - 2-3 practical examples
14. **TESTING** - How to test
15. **TROUBLESHOOTING** - Common problems + solutions
16. **NEXT STEPS** - Priority actions + known gaps
17. **TECH STACK** - Technologies used
18. **TAGS** - Searchable tags
19. **METADATA** - Creator, dates, version
20. **RELATED DNAS** - Cross-references
