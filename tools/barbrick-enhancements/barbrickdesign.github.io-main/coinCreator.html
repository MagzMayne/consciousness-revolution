Token Name Platform — Complete Project Launcher

Creates the full project (backend, frontend, scripts, data) in a folder you choose using the File System Access API.

Install steps

  • Click “Choose install folder” and select a destination directory.
  • Optionally edit the treasury address and port below.
  • Click “Install project” to write all files and folders.
  • Open a terminal in the destination folder and run: 
    npm install
npm run setup
npm run scan
npm start
# Then open http://localhost:8080

Note: This project excludes auto-clicking and automated trading. Mouse guidance (vision) is assistive only.
