White-card Protocol (CAC/PIV-aware)

This manager accepts a white-card package signed with a CAC/PIV certificate or an attached PKCS#11-exported signature, validates required fields aligned with SecDev CAC practices, redacts PII on request, and stages a tamper-evident submission package for authorized operators. CAC usage and middleware requirements align with DoD guidance on CAC readers and PKI modernization.
Validation rules implemented client-side for staging: legal_name required, EIN or DUNS required, NAICS required, contact.email required; signature must be present or CAC fingerprint supplied; staged package includes signed timestamp and audit hash; redaction replaces PII fields before staging and stores redaction audit trace.
