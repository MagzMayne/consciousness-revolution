Bloomers Ledger — single-file public hub Save this file as BloomersLedger.html. It’s a single-file deployable hub that: • hosts a public project ledger for BarBrickDesign with project entries, commit-like updates, time tracking, and file attachments • supports drag-and-drop or file input for images, code, and notes and computes SHA-256 hex fingerprints for uploads • records time entries, durations, tags, and contributor names into a local ledger stored in localStorage (exportable as JSON) • provides an optional “publish” mode that builds a read-only public view of selected entries for sharing on a site or GitHub Pages • includes the BloomersTattoos pixel-flow demo loader and hex fingerprint integration so project work tied to images (activation layers) is visible in the ledger • runs fully in the browser with no server required and contains no wallet or on-chain transaction code Copy the entire file below into BloomersLedger.html, open it in a modern browser, and put your demo images (e.g., X9dvbXGFGnkKR919MoaBt.jpeg) beside it if you want them available as defaults.
