## 📝 Notes

### Repository Naming Convention
- Use lowercase with hyphens
- Keep names descriptive but concise
- Examples: `government-grants-portal`, `ai-grid-link-plc`

### GitHub Pages Configuration
- All repos should enable GitHub Pages
- Deploy from `main` branch, `/` directory
- Update DNS if custom domains needed

### Synchronization Strategy
- Hub → Project: Daily automated sync (2 AM UTC)
- Project → Hub: Manual PR process (quality control)
- Conflict resolution: Hub always wins (source of truth)
