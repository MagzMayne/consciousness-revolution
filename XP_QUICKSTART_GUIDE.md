# XP Rewards System - Quick Start Guide

## For Project Owners

### Adding Your First Project

1. **Visit the Marketplace**
   - Go to [central-dev-marketplace.html](central-dev-marketplace.html)
   
2. **Click "Add Project"**
   - Click the gold "➕ Add Project" button in the header
   
3. **Fill in the Form**
   - **Repository URL:** Your GitHub/GitLab/Bitbucket repo URL
   - **Title:** Clear project name
   - **Description:** What your project does
   - **Completion:** How complete is it? (0-100%)
   - **Status:** Working, Partial, Broken, or Untested
   
4. **Submit and Earn XP**
   - You'll instantly earn **500 XP** for adding a project!
   - Your project is now visible to all developers

### Managing Your Projects

- **View Your Projects:** Switch to "My Projects" tab
- **Track XP:** See XP value for each project
- **Find Contributors:** Developers can help complete your projects

## For Contributors

### Finding Projects to Work On

1. **Browse the Marketplace**
   - Go to [central-dev-marketplace.html](central-dev-marketplace.html)
   
2. **Find Projects That Need Help**
   - Click "🚧 Need Help" tab
   - These are incomplete or partially working projects
   
3. **Filter by Interest**
   - Use the status filters (Working, Partial, Broken)
   - Search by keyword or technology
   
4. **Check XP Values**
   - Each project shows its XP value
   - Higher complexity = More XP

### Making Contributions

**Current Process (Manual):**
1. Fork the project repo
2. Make your changes
3. Submit a pull request
4. Contact project owner for approval
5. Once approved, XP is awarded

**Future (Automated):**
- System will auto-detect commits
- XP awarded automatically on merge

## Understanding XP and Tokens

### How Much XP Can You Earn?

| Contribution | Base XP | With Multipliers |
|-------------|---------|------------------|
| Bug Fix (Simple) | 100 XP | 150-300 XP |
| Feature (Medium) | 250 XP | 375-750 XP |
| Feature (Complex) | 250 XP | 750-1,875 XP |
| Project Completion | 1,000 XP | 1,500-9,000 XP |

### XP to Crypto Conversion

```
100 XP = 1 Governance Token
1 Token = $0.01 USD (starting value)

Examples:
- 1,000 XP = 10 tokens = $0.10
- 10,000 XP = 100 tokens = $1.00
- 100,000 XP = 1,000 tokens = $10.00
```

### Leveling Up

```
Level 1: 100 XP
Level 5: 2,500 XP
Level 10: 10,000 XP
Level 20: 40,000 XP
Level 50: 250,000 XP
```

## FAQ

**Q: How long does approval take?**
A: Typically 1-3 days. Project owners review contributions.

**Q: Can I lose XP?**
A: No, XP is permanent once earned and approved.

**Q: What if my contribution is rejected?**
A: No penalty. You can revise and resubmit.

**Q: How accurate is the XP calculation?**
A: XP is calculated based on standard rates. Project owners can adjust for exceptional work.

**Q: When can I cash out?**
A: Crypto payments coming Q1 2026. You can still earn XP now!

**Q: What's the governance token for?**
A: Vote on platform features, unlock premium tools, trade on exchanges.

**Q: Is there a mobile app?**
A: Not yet, but all dashboards are mobile-responsive.

**Q: Can teams share XP?**
A: Yes, XP can be distributed among team members based on contributions.
