Feedback Widget Test Page

Universal Feedback System - Live Demo

📝 Widget Features

  • Position: Bottom-left corner (opposite of ARAYA)
  • Feedback Types: Bug Report, Feature Request, Upgrade Idea, Compliment, Other
  • Auto-captures: Page URL, timestamp, viewport size, user agent
  • Privacy: All submissions are anonymous by default
  • Backend: Stores in Supabase via Netlify function
✅ WIDGET ACTIVE
Keyboard Shortcut: Press Ctrl + Shift + F to open the feedback modal

Testing Instructions

1. Look for the 📝 button in the bottom-left corner
2. Click it to open the feedback modal
3. Select a feedback type and submit a test message
4. Verify ARAYA responds with confirmation

To add this widget to any page, include:

<script src="/components/feedback-widget.js"></script>
