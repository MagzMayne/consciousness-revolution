API ENDPOINTS
────────────────────────────────────────────────────────────────────────
GET  /.netlify/functions/spiral-progress?userId=xxx
POST /.netlify/functions/spiral-progress

ACTIONS (POST body):
  initialize      - Start new user (Reality L1)
  add_xp          - Award XP (requires: forgeSlug, amount, source)
  check_octave    - Check if user hit Infinity L13
  get_leaderboard - Rankings (optional: forgeSlug)
  get_xp_history  - Transaction log (optional: forgeSlug)

XP SOURCES:
  daily_login, mission_complete, challenge_win, content_create,
  community_help, purchase, bonus, admin_grant, correction

spiral_level_ups          - Level-up history
