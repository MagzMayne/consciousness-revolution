## Maintenance

### When Adding New Barbrick Tools
1. Identify which domain(s) they support
2. Add to domain-specific portals
3. Update `BARBRICK_INTEGRATION_SUMMARY.md`
4. Ensure they complement (not replace) consciousness tools

1. Identify which domain they belong to
2. Add to main consciousness navigation
3. Update consciousness-tools.html
4. Maintain focus on awareness and pattern recognition
