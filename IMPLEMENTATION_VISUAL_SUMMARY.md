## 💾 System Architecture

### Data Flow
```
User Adds Project
       ↓
Repository URL
       ↓
Parse URL (GitHub/GitLab/Bitbucket)
       ↓
Fetch Metadata via API
       ↓
Auto-Categorize
       ↓
Calculate XP Value
       ↓
Store in LocalStorage
       ↓
Display in Widget
       ↓
Award Creation XP (500)
```

### XP Calculation
```
Contribution Type (Base XP)
       ↓
Apply Complexity Multiplier (1x-3x)
       ↓
Apply Completion Bonus (1x-2x)
       ↓
Apply Functionality Multiplier (0.5x-1.5x)
       ↓
Final XP Amount
       ↓
Update User Total
       ↓
Calculate Tokens (XP / 100)
       ↓
Calculate USD Value (Tokens * $0.01)
       ↓
Update Level (sqrt(XP / 100))
```

### Storage Structure
```
localStorage:
  ├─ xp-reward-system
  │  ├─ userXP: Map<userId, totalXP>
  │  └─ contributionHistory: Map<userId, contributions[]>
  │
  └─ project-contribution-tracker
     ├─ projects: Map<projectId, projectData>
     ├─ developers: Map<developerId, developerData>
     ├─ contributions: Contribution[]
     └─ incompleteProjects: Map<projectId, projectData>
```
