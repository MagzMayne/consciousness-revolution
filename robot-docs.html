🤖 ARAYA 3D ROBOT ASSISTANT

Modern Evolution of the Classic Office Assistant, Powered by Consciousness

🎯 Overview

The ARAYA 3D Robot Assistant is a fully animated, autonomous AI helper that appears on screen to visualize AI activity and provide an interactive, consciousness-aware experience. It's like the classic Microsoft Office Assistant (Clippy), but way more advanced with 3D graphics, autonomous behavior, and state persistence across pages.

Key Innovation: The robot maintains its position, state, and personality across all pages using the same localStorage/sessionStorage system as ARAYA chat, creating a seamless, unified experience throughout the platform.

✨ Features

🎨 3D Rendering

Built with Three.js for smooth, hardware-accelerated 3D graphics with ARAYA's signature cyan, gold, and purple color scheme.

🚶 Walking Animation

Realistic walking animation with leg swing, arm movement, and body rotation. The robot walks around the screen autonomously.

💾 State Persistence

Position, animation state, and session data saved to localStorage and restored across page navigation and browser sessions.

🔄 Session Sync

Uses the same session ID as ARAYA chat, so the robot is tied to your user identity and chat memory.

🤖 Autonomous Behavior

When idle for 3+ seconds, the robot starts wandering around autonomously, staying within screen boundaries.

🎭 Multiple States

Four animation states: idle (gentle bobbing), walking, thinking (head rotation), and speaking (head bob + arm gestures).

⚡ Event Integration

Responds to ARAYA chat events - switches to "thinking" when you send a message, "speaking" when ARAYA responds.

📱 Responsive Design

Adapts to different screen sizes with boundary detection and responsive sizing. Works on desktop, tablet, and mobile.

📋 How to Use

For Developers - Adding to New Pages

Simply add this line before closing </body> tag:

<script src="/js/robot-assistant-loader.js"></script>

That's it! The robot will automatically appear on the page.

For Developers - Controlling the Robot

// Move robot to specific coordinates
RobotAssistantLoader.moveTo(500, 300);

// Change animation state
RobotAssistantLoader.setState('thinking'); // idle, walking, thinking, speaking

// Set action message
RobotAssistantLoader.setAction('Processing your request...');

// Get current state
const state = RobotAssistantLoader.getState();
console.log(state.position, state.animationState);

For Users

  • The robot appears on the lower-left corner of the screen
  • It wanders around autonomously when idle
  • When you interact with ARAYA chat, the robot shows what's happening:
    • Thinking animation when you send a message
    • Speaking animation when ARAYA responds
  • The robot remembers its position when you navigate between pages

🎨 Robot Design

The robot is built from geometric primitives, matching ARAYA's visual aesthetic:

  • Head: Cyan sphere with glowing eye (gold sphere)
  • Body: Purple box (torso)
  • Arms: Cyan cylinders
  • Legs: Gold cylinders
  • Antenna: Purple cylinder with gold sphere tip
  • Lighting: Ambient + directional + accent point light for depth
  • Materials: Phong shading with emissive glow
