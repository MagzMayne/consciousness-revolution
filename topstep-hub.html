📖 About TopStep Trading Hub

🎯 What is TopStep Trading Hub?

TopStep Trading Hub is a comprehensive multi-account management platform designed for futures traders. It enables you to manage unlimited TopStep trading accounts from a single, unified dashboard with advanced features like copy trading, real-time synchronization, performance analytics, and automated signal distribution.

Whether you're managing demo accounts to practice strategies or coordinating multiple funded accounts, this hub provides the tools you need to maximize your trading efficiency and profitability.

🚀 How to Use This Hub

Step 1: Authentication

• Login with your existing account or Create Account to get started
• Use Preview as Guest to explore features without registration
• Your credentials are securely stored and encrypted

Step 2: Create Your First Account

• Click "➕ Add Account" in the "My Accounts" section
• Enter account details (name, email, type, initial balance)
• Choose account type: Demo (practice), Combine (evaluation), or Funded (live)
• Click "Create Account" to add it to your hub

Step 3: Configure API Integration (Optional)

• Click "⚙️ API Settings" in the header
• Enter your TopStepX username and API key (get from TopStepX platform)
• Enable auto-sync for automatic data synchronization
• Configure sync interval and real-time data preferences
• Click "🔌 Test Connection" to verify setup

Step 4: Set Up Copy Trading (Optional)

• Click "👤 Make Master" on an account with strong performance
• Click "📊 Manage" in the Copy Trading section
• Select a master trader to follow from your accounts
• Configure copy settings: ratio, contract filters, signal types
• Enable the copy relationship to start replicating trades

Step 5: Start Trading

• Click "📈 Trade" on any account to open the trading interface
• Monitor performance in real-time through the dashboard
• View statistics: Total Balance, P&L, Trades, Win Rate
• Track top performers in the leaderboard section
• Use "🔄 Sync Now" to manually refresh data

Additional Features

• Upgrade Plan: Access premium features with subscription tiers
• API Dashboard: View detailed API connection status and metrics
• Account Management: Edit, delete, or toggle master trader status
• Performance Tracking: Monitor win rates, profit factors, and Sharpe ratios

💡 Pro Tip: Start with a demo account to familiarize yourself with the interface, then create multiple accounts to test copy trading strategies before moving to funded accounts.
