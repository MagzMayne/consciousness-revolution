## Getting Started

1. **Open Dashboard**
   ```
   https://barbrickdesign.github.io/management-agent-dashboard.html
   ```

2. **Start Monitoring**
   - Click "▶️ Start Monitoring"
   - Agent begins continuous monitoring

3. **Run Initial Scan**
   - Click "🔍 Run Scan Now"
   - Agent tests all functionality

4. **Apply Fixes**
   - Click "🔧 Apply Fixes"
   - Agent automatically repairs issues

5. **View Logs**
   - Scroll through recent logs
   - Export logs as JSON
   - Generate HTML reports
