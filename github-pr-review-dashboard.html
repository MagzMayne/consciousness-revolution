ℹ️ How It Works

1. Configure: Set your GitHub token and repository details

2. Fetch: Get review request notifications from GitHub

3. Validate: Agent analyzes PR changes, runs checks

4. Approve: If validation passes, PR is approved

5. Merge: Approved PRs are automatically merged

GitHub Token Permissions Required:
  • notifications (read)
  • pull_requests (read/write)
  • contents (read)
  • statuses (read)
