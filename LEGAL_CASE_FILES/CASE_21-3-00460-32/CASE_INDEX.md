## WORKFLOW FOR NEW HEARINGS

1. Create folder: `HEARINGS/YYYY-MM-DD_[DESCRIPTION]/`
2. Copy `HEARINGS/HEARING_TEMPLATE.md` into folder
3. Fill out PRE-HEARING PREP section before hearing
4. Record hearing (screen record Zoom or attend in person)
5. Run transcriber: `python .consciousness/COURT_TRANSCRIBER.py <video>`
6. Move recording + transcript into folder
7. Fill out RULING SUMMARY and ACTION ITEMS after hearing
8. Request official court recording ($25, Clerk's Room 300)
9. Update this CASE_INDEX.md
