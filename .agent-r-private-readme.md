## 🔧 Technical Details

### Activation Detection

The system listens for:
- All text input events
- All paste events
- Keyboard shortcuts (Ctrl+Shift+R)
- URL parameters (?agentR=activate)

### Session Management

```javascript
sessionStorage.setItem('agentR_active', 'true');
sessionStorage.setItem('agentR_sessionId', sessionId);
sessionStorage.setItem('agentR_timestamp', timestamp);
```

### Custom Instructions

Custom instructions are automatically injected as:
1. Hidden div in DOM with JSON data
2. Data attributes on chat inputs
3. Window object properties

### Project Loading

Projects loaded from:
- `/projects.json` (API)
- Hardcoded core systems
- Dynamic discovery

### Agent System Loading

Agents loaded from:
- `/src/ai/agent-mappings.js`
- Agent manifest definitions
- Dynamic imports

## 🐛 Troubleshooting

### Activation Not Working?

1. Check browser console for errors
2. Verify script loaded: `window.agentR`
3. Try manual activation: `window.agentR.activate()`
4. Use fallback: Copy-paste activation message

### Banner Not Appearing?

1. Check if activation succeeded in console
2. Try force activate: `window.agentR.forceActivate()`
3. Verify no CSS conflicts
4. Check z-index settings

### Projects Not Loading?

1. Verify network connection
2. Check `/projects.json` exists
3. Look for CORS errors
4. Use hardcoded projects fallback
