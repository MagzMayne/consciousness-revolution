🔄 The "Filter" — barbrickdesign ↔ consciousness-revolution

Yes — there is a deliberate medium between barbrickdesign.github.io and consciousnessrevolution.io. Two GitHub Actions workflows control what moves in each direction:

Workflow Direction Schedule Philosophy
daily-barbrickdesign-sync.yml barbrickdesign → CR Daily @ 02:00 UTC ADDITIVE ONLY — new files import; existing files never overwritten
sync-to-barbrickdesign.yml CR → barbrickdesign On push to main (dashboard.html) Specific shared pages pushed back with domain-substitution
What the filter does: Only files with extensions .html .md .js .css .json .txt are synced. Core config files (package.json, netlify.toml, CNAME, etc.) are never imported — preventing accidental overwriting of deployment config. Files already present in consciousness-revolution are also never overwritten — only net-new content flows in.
