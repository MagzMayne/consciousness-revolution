# AI Proctor Enhancement - User Guide

## Overview

The Barbrick Developer Certification Academy has been enhanced with three powerful AI systems that work together to provide intelligent assistance and reward contributions.

## 1. Local LLM Engine (Offline AI)

### What is it?
A comprehensive knowledge base that provides intelligent responses without requiring an API key. It works completely offline!

### Features
- **5 Knowledge Domains**: Scrum, Product Ownership, Cloud/DevOps, AI/Data, Security
- **150+ Expert Responses**: Covering all certification topics
- **Smart Context Awareness**: Understands your current section and learning path
- **Quick Answers**: Instant responses to common questions
- **Progressive Learning**: Responses adapt based on your conversation history

### How to Use
1. Click the AI Proctor orb (floating icon on the right)
2. Ask any question related to certifications
3. If you don't have an API key, the Local LLM automatically provides responses
4. The system will indicate it's using "Local AI Response"

### Example Questions
- "What's the difference between PSM and PSPO?"
- "How do I prepare for the exam?"
- "Explain Scrum artifacts"
- "What cloud certifications do you offer?"

## 2. API Key Contribution System

### What is it?
Share your OpenAI, Anthropic, or other API keys with the community and earn points for every API call made using your key.

### Earning Structure
- **Base Rate**: 1-2 points per API call
- **Premium Keys**: 1.5-2.0x multiplier
- **Success Bonus**: +10% for successful calls
- **High Complexity**: +50% for complex queries

### How to Contribute
1. Sign in to your account
2. Navigate to "Earn" → "API Keys" tab
3. Click "Contribute API Key"
4. Enter your API key and select the service
5. Choose sharing preferences (all users vs premium only)
6. Your key is encrypted and securely stored

### Contribution Settings
- **Share with Community**: Allow all students to use your key
- **Premium Only**: Restrict to premium tier students (higher rewards)
- **Daily Usage Limit**: Set maximum calls per day (default: 1000)
- **Auto-Renew**: Keep contribution active automatically

### Tracking Your Earnings
- View real-time usage stats
- See which services are most used
- Check your leaderboard ranking
- Monitor recent activity

## 3. Node Hosting System

### What is it?
Allocate storage, RAM, and bandwidth from your computer to support the platform infrastructure. Earn automatic rewards based on uptime and resource contribution.

### Earning Structure

**Storage Rewards**:
- 0.5 points per GB per day
- High availability bonus: 1.5x multiplier (99%+ uptime)

**RAM Rewards**:
- 1.0 points per GB per day
- High availability bonus: 1.5x multiplier (99%+ uptime)

**Bandwidth Rewards**:
- 0.1 points per GB transferred
- High-speed bonus: 1.3x multiplier

**Uptime Rewards**:
- 10 points per day at 100% uptime
- Minimum 95% uptime required for rewards

### How to Host a Node
1. Sign in to your account
2. Navigate to "Earn" → "Node Hosting" tab
3. Set your resource allocation:
   - **Storage**: Minimum 1 GB (recommended: 10-100 GB)
   - **RAM**: Minimum 0.5 GB (recommended: 2-8 GB)
   - **Bandwidth**: Minimum 10 GB/month (recommended: 100-1000 GB)
4. Click "Start Hosting"
5. Keep your browser open or run our node client

### Maximizing Earnings
- **Keep High Uptime**: 99%+ gets 1.5x rewards
- **Allocate More Resources**: More GB = more points
- **Use Reliable Connection**: Ethernet or fiber preferred
- **Run 24/7**: Consistent uptime is key
- **Monitor Performance**: Check stats regularly

### Example Earnings
Allocation: 10 GB storage, 2 GB RAM, 100 GB bandwidth, 99% uptime
- Storage: 10 × 0.5 × 1.5 = 7.5 pts/day
- RAM: 2 × 1.0 × 1.5 = 3.0 pts/day
- Uptime: 10 × 0.99 × 1.5 = 14.85 pts/day
- **Total**: ~25 pts/day = 750 pts/month

## FAQ

**Q: Do I need both API keys and node hosting?**
A: No! You can do either or both. Each earns points independently.

**Q: What happens if my API key runs out of credits?**
A: The system will detect the error and temporarily pause using your key. You won't earn points during this time.

**Q: Can I stop hosting at any time?**
A: Yes! Simply deactivate your node. You'll receive your earned points up to that moment.

**Q: How long does it take to earn 100 points?**
A: Depends on contribution:
- API keys: 50-100 API calls (varies by complexity)
- Node hosting: 4-7 days with modest resources
- Combined: 2-4 days is typical

**Q: Is this safe?**
A: Yes! All systems include:
- Encryption and secure storage
- Audit logging
- Usage limits and controls
- Ability to stop anytime

**Q: Can I see who uses my contributions?**
A: You see anonymous user IDs, not personal information. This protects privacy while maintaining transparency.

**Q: What if I want to upgrade my contribution?**
A: You can add more API keys or register additional nodes anytime. Each contribution is tracked separately.
