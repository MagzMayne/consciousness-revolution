# Project consolidation and merge plan This captures all features discussed, organizes them into a clean deliverable, and ensures we ship a mobile‑friendly dashboard with live pricing, steep per‑type differentials, and deflationary Sparklet mechanics. It ends with a complete, single‑file HTML (scripts included) ready to deploy. --- ## Objectives - Live, deflationary pricing tied to Sparklet market cap and circulating supply. - Steep per‑type price differentials within tiers using inverse‑square scarcity weighting. - $10 base for Standard packs; higher tiers scale steeply while staying dynamic. - Clean, mobile‑first UI with clear tables, controls, and a “what to buy” roadmap. - Modular code: easy to adjust mint costs, tier anchors, allocations, and burn rules. --- ## Todo list ### Data and configuration - **Seed registry:** Define each seed type with rarity and supply (from your latest counts). - **Tier anchors:** Set target average price per tier (Standard = $10 baseline, Limited ≈ $100, Rare ≈ $1,000, Ultra‑Rare ≈ $10,000). - **Mint costs:** Configure Sparklet mint costs per rarity (e.g., Standard 100, Limited 150, Rare 200, Ultra‑Rare 300). - **Allocations (optional):** Allow percentage allocations per rarity; keep model driven by anchors + scarcity. - **Holders display:** Show approximate holders (~3,000) for context; do not hard‑depend on it for price. ### Core pricing logic - **Sparklet price:** Price = Market Cap ÷ Sparklet Circulating Supply. - **Deflation/Burn:** When minting, subtract the mint cost from Sparklet supply; recompute Sparklet price live. - **Per‑type price (extra steep):** Use inverse‑square weighting in each tier so scarcer types cost more: - Compute per‑type weight = 1 / supply². - Normalize weights within the tier so the weighted average equals the tier anchor. - Final USD price per seed = TierAnchor × normalizedWeight. - **Alternative path:** Also compute mint‑cost × SparkletPrice (for reference), but display steep model as primary. ### UI/UX - **Mobile‑first layout:** Single column, sticky controls, readable tables, large tap targets. - **Controls:** Inputs for market cap, Sparklet supply, tier anchors, multipliers, rarity allocations, and a burn toggle. - **Tables:** Live updating seed table with per‑type price, supply, rarity, share. - **Roadmap:** “What to buy” recommendations based on price‑to‑scarcity leverage and budget. - **Theme:** Light, clean, accessible color contrast; system font stack for performance. - **Persistence:** Save settings to localStorage so values persist between sessions. ### Interactions - **Mint simulation:** Buttons to simulate minting packs (burn Sparklet), update supply if applicable, recompute prices. - **Filters/sort:** Sort by price, rarity, supply; filter by rarity. - **Validation:** Guard against zero/negative values; clamp ranges; give clear messages. - **Performance:** Debounce slider/inputs; compute once per tick; reuse DOM nodes. ### Testing and safety - **Edge cases:** Very small supplies, changing allocations, large burns, mobile viewport widths. - **Numeric stability:** Avoid division by zero; cap extreme outputs; format currency with separators. - **Accessibility:** Labels, aria roles, focus states, keyboard navigation, no tiny text. ### Merge checklist - **Unify logic:** Replace prior mild-weight tables with extra‑steep inverse‑square model tied to $10 base. - **Integrate deflation:** Live Sparklet supply and price recalculation on mint. - **Confirm tiers:** Anchors default to 10/100/1,000/10,000; user-adjustable with sensible bounds. - **Finalize UI:** Responsive CSS, mobile layout, sticky header inputs. - **Persist and defaults:** Load prior settings from localStorage; fall back to sensible defaults. - **Ship single file:** Deliver a standalone HTML with scripts and styles embedded. --- # Complete HTML with all scripts included ```html Sparklet Economy Dashboard
