# Offline Translator - User Guide

## What is This?

The **translator.html** is a powerful, offline-capable voice translator that works completely without internet access. It's designed for emergency situations, field operations, international travel, and anywhere you need instant translation but don't have reliable internet connectivity.

## Key Features

✅ **Works Completely Offline** - No internet required after initial download  
✅ **12 Languages Supported** - English, Spanish, French, German, Chinese, Japanese, Arabic, Hindi, Russian, Portuguese, Italian, Korean  
✅ **Auto Language Detection** - Automatically detects what language is being spoken  
✅ **Voice Input & Output** - Speak in one language, hear translation in another  
✅ **Instant Translation** - Less than 1 millisecond response time  
✅ **Mobile Friendly** - Works on phones, tablets, and computers  
✅ **Privacy Focused** - No data sent to external servers in offline mode  
✅ **Tiny File Size** - Only 69KB, fits on any device  

## How to Use

### Getting Started

1. **Download the File**
   - Save `translator.html` to your device
   - No installation needed - it's a single HTML file
   - Works on any device with a web browser

2. **Open the Translator**
   - Double-click `translator.html` (desktop)
   - Open with browser app (mobile)
   - Works offline once downloaded

3. **Allow Microphone Access** (Optional)
   - For voice input, click "Allow" when prompted
   - Not required for text-only translation

### Two Modes of Operation

#### Mode 1: Pair Conversation
Best for one-on-one conversations between two people.

**How it works:**
- You speak in your language → Translated to their language
- They speak in their language → Translated to your language
- Great for: Medical consultations, business meetings, personal conversations

**Setup:**
1. Click "Pair conversation" tab
2. Select "Listen in" language (your language)
3. Select "Partner speaks" language (their language)
4. Click "Start listening"

#### Mode 2: Open Listen
Best for understanding speech in your environment.

**How it works:**
- Listens to any speech around you
- Auto-detects the language being spoken
- Translates everything to your chosen language
- Great for: Announcements, lectures, group discussions

**Setup:**
1. Click "Open listen" tab
2. Select "Listen in" language (your language)
3. Click "Start listening"

### Translation Options

#### Input Settings
- **Auto-detect**: Let the app figure out what language is being spoken
- **Specific Language**: Choose if you know the source language

#### Output Settings
- **Listen in**: Choose your preferred language for translations
- **Voice Gender**: Select male/female/any for speech output
- **Auto-play audio**: Toggle automatic speech output on/off

## Tips for Best Results

### For Voice Recognition

✅ **DO:**
- Speak clearly and at normal speed
- Use short sentences
- Pause between phrases
- Speak directly toward microphone

❌ **DON'T:**
- Whisper or shout
- Speak too fast
- Use slang or idioms
- Talk with mouth full

### For Translation Quality

✅ **DO:**
- Use common words and phrases
- Keep sentences simple
- Use dictionary words when possible
- Check the transcription first

❌ **DON'T:**
- Use complex idioms
- Mix multiple languages
- Use technical jargon
- Expect perfect grammar

### Battery Saving Tips

💡 **Mobile devices:**
- Reduce screen brightness
- Close other apps
- Use airplane mode (offline mode)
- Turn off auto-play for longer sessions

## Troubleshooting

### "No microphone access"
**Solution:** Grant microphone permission in browser settings
- Chrome: Settings → Privacy → Site Settings → Microphone
- Safari: Settings → Safari → Camera & Microphone Access
- Firefox: Settings → Privacy → Permissions → Microphone

### "Speech recognition not supported"
**Solution:** Use a compatible browser
- ✅ Chrome (best support)
- ✅ Safari (iOS/macOS)
- ✅ Edge
- ❌ Firefox (limited support)

### "Translation seems wrong"
**Solutions:**
1. Check if word is in dictionary (common words work best)
2. Rephrase using simpler words
3. Try text input instead of voice
4. Go online for extended vocabulary

### "Audio output not working"
**Solutions:**
1. Check device volume
2. Enable auto-play in settings
3. Manually click "Replay output"
4. Grant audio permission in browser

### "App is slow"
**Solutions:**
1. Close other browser tabs
2. Restart browser
3. Clear browser cache
4. Use on newer device if possible
