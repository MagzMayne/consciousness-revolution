📚 How to Get API Keys

⚡ Groq API Key (FREE - Recommended)

  1. Go to console.groq.com/keys
  2. Sign in with Google or email (free)
  3. Click "Create API Key"
  4. Copy the key (starts with gsk_)
  5. Free tier: 14,400 requests per day!

💡 Best choice for free AI! Fast responses, high quality.

🤗 HuggingFace Token (FREE)

  1. Go to huggingface.co/settings/tokens
  2. Sign in or create free account
  3. Click "New token" → "Read" access
  4. Copy the token (starts with hf_)
  5. Free tier: Rate limited but sufficient

💡 Great for image generation! Includes Stable Diffusion models.

🤖 OpenAI API Key (Paid)

  1. Go to platform.openai.com/api-keys
  2. Sign in or create an account
  3. Click "Create new secret key"
  4. Copy the key (starts with sk-)
  5. Add billing information to enable usage

Cost: $0.001 - $0.06 per 1K tokens

🪙 CoinGecko API Key

  1. Go to coingecko.com/en/api/pricing
  2. Choose a plan (Free tier available)
  3. Sign up and verify email
  4. Copy API key from dashboard

📈 Alpha Vantage API Key

  1. Go to alphavantage.co/support/#api-key
  2. Enter your email and claim free API key
  3. Check your email for the key
  4. Free tier includes 25 requests per day
