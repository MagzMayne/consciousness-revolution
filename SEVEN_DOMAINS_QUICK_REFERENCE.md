## 🚀 Quick Start

### Access the Dashboard
```
https://consciousnessrevolution.io/SEVEN_DOMAINS_DASHBOARD.html
```

### Upload a Document
1. **Choose a tool** (e.g., Contract Analyzer)
2. **Click "Choose File"** button
3. **Select document** (PDF, DOC, TXT, etc.)
4. **Wait for upload** (status shows progress)
5. **Review extracted text** (appears in textarea)
6. **Click "Analyze"** (get instant results)

### Start the Backend (Optional but Recommended)
```bash
# Windows
START_DOCUMENT_PROCESSOR.bat

# Mac/Linux
python DOCUMENT_PROCESSOR.py
```

## 🔧 Backend Features

### Supported File Types
- **Documents**: PDF, DOC, DOCX, TXT, RTF
- **Email**: EML, MSG
- **Data**: CSV, XLSX, JSON, XML
- **Images**: JPG, PNG (for OCR in future)
- **Audio**: MP3, WAV (for transcription in future)

### File Size Limits
- **Maximum**: 50 MB per file
- **Recommended**: < 10 MB for faster processing

✅ Filename sanitization  
✅ SHA256 checksums  
✅ Local storage only  
✅ No cloud upload  

## 💡 Pro Tips

### For Contracts
1. **Always read fully** - Tools highlight issues but aren't legal advice
2. **Focus on red flags** - Negotiate the worst clauses first
3. **Get it in writing** - Verbal promises don't count
4. **Ask questions** - Every clause is negotiable
5. **Walk away if needed** - If they refuse all changes, that's information

### For Email Analysis
1. **Trust your gut** - If it feels off, it probably is
2. **Verify independently** - Never trust links in suspicious emails
3. **Check sender** - Confirm through separate channel
4. **Watch for urgency** - Pressure tactics are red flags
5. **Document everything** - Save concerning communications

### For Negotiations
1. **Know your BATNA** - Best Alternative To Negotiated Agreement
2. **Focus on interests** - Not positions
3. **Take your time** - Artificial urgency is a tactic
4. **Get it documented** - Written agreement protects both parties
5. **Be willing to walk** - Sometimes no deal is best deal

### For Meeting Analysis
1. **Take notes** - Document who said what
2. **Track time** - Who speaks most? Who's silenced?
3. **Watch for patterns** - Repeated tactics are intentional
4. **Set boundaries** - Push back on aggressive behavior
5. **Follow up in writing** - Confirm decisions via email

## 🆘 Quick Troubleshooting

| Problem | Solution |
|---------|----------|
| File won't upload | Check size < 50MB, correct format, backend running |
| Backend not starting | Install dependencies: `pip install -r requirements-document-processor.txt` |
| Analysis not working | Refresh page, check console, try smaller text |
| Links don't work | Verify file paths, check domain pages exist |
| Slow performance | Use smaller files, close other tabs, restart backend |
