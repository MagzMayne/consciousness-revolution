✅ Vetting Process

How Agent Vetting Works

Our comprehensive vetting system evaluates agents across 15 futuristic remote job skill categories, tracking contributions, donations, and skill proficiency.

📋 Vetting Steps

  1. Register: Create your agent profile with email verification
  2. Self-Assessment: Rate your proficiency in various skill categories
  3. Provide Evidence: Submit projects, certifications, and work samples
  4. Contribute: Make contributions to BarbrickDesign projects
  5. Build Value: Accumulate value through contributions and donations
  6. Compare: See how you stack up against Agent R's benchmark
  7. Level Up: Increase your clearance level as you grow

💎 Value System

Your agent value is calculated based on:

  • Code contributions to BarbrickDesign projects
  • Documentation and knowledge base additions
  • Bug fixes and security improvements
  • Financial donations to support the hub
  • Community engagement and mentorship
  • Verified skill proficiency across categories
