# Team Launchpad Hub - Quick Start Guide

## 🚀 Getting Started in 5 Minutes

### Step 1: Register as an Agent (2 minutes)

1. **Open the Agent Vetting Dashboard**
   ```
   Open: agent-vetting-dashboard.html
   ```

2. **Click "Quick Registration"** in the blue banner at the top

3. **Fill in your details:**
   - Name: Your full name
   - Email: Your contact email
   - Skills: Your primary skills (comma-separated)
   
   Example: `JavaScript, React, Node.js, Python, AI/ML`

4. **Submit** - You'll get an Agent ID and be redirected to the hub

### Step 2: Add Your First Repository (2 minutes)

1. **Click the "+ Add Repo" button** in the Active Projects section

2. **Fill in the repository form:**
   - **Repository URL:** `https://github.com/yourusername/yourrepo`
   - **Project Name:** Your project name
   - **Description:** Brief description of what it does
   - **Technologies:** List the tech stack (comma-separated)
   - **Category:** Select the best fit

3. **Click "Add Repository"** - Your project is now added!

### Step 3: Discover Matches (1 minute)

1. **Add a second repository** following the same steps

2. **Watch the magic happen:**
   - System automatically analyzes both projects
   - Match percentage calculated
   - Merge suggestions generated
   - Displayed in "Project Matches & Merge Suggestions"

## 💡 Pro Tips

### Matching Algorithm

The system looks for:
1. **Technology overlap** (50% of score)
2. **Same category** (30% of score)
3. **Description similarity** (20% of score)

**To maximize matches:**
- Use common technology names (React, not React.js)
- Choose accurate categories
- Write descriptive project descriptions
- Include multiple technologies

### Best Practices

**Adding Repos:**
- ✅ Use complete GitHub URLs
- ✅ Write clear descriptions
- ✅ List all major technologies
- ✅ Choose appropriate category
- ❌ Don't use shortened URLs
- ❌ Don't skip required fields

**Agent Skills:**
- ✅ List specific technologies
- ✅ Use industry-standard names
- ✅ Include frameworks and tools
- ✅ Separate with commas
- ❌ Don't use vague terms like "coding"
- ❌ Don't use special characters

## 🔧 Troubleshooting

### No Matches Showing?

- **Need 2+ repos** - Add at least two repositories
- **Check similarity** - Projects must have some overlap
- **Match threshold** - Must be at least 40% similar
- **Refresh** - Click the "Refresh" button

### Can't Add Repo?

- **Check URL format** - Must be valid GitHub URL
- **Fill required fields** - All marked fields are required
- **Clear browser cache** - Sometimes helps
- **Try different browser** - Chrome, Firefox, Safari work best

### Data Not Saving?

- **Enable localStorage** - Check browser settings
- **Clear quota** - Browser may have storage limits
- **Disable private mode** - localStorage disabled in private browsing
- **Check console** - Open browser console for errors
