DNA: Voice Activation

"Hey Claude" - Voice Commands and Speech Integration

PROJECT DNA
Category: INTERFACE
STATUS: LIVE

1. WHAT IS IT?

Purpose: Voice-controlled interface for the consciousness system. Say "Hey Claude" or "Hey Commander" to activate, then speak commands naturally.

Capabilities

  • Wake Word Detection: Always-on listening for "Hey Claude", "Hey Commander"
  • Multi-Agent Routing: Voice routes to C1/C2/C3 Trinity agents based on keywords
  • Text-to-Speech: System speaks responses aloud
  • S24 Phone Integration: Voice control for Samsung S24 via ADB
  • Analytics: All voice interactions logged with performance metrics

2. KEY FILES

File Purpose
repos/voice-command-system/VOICE_WAKE_WORD_LISTENER.py Always-on wake word detection ("Hey Claude", "Hey Commander")
repos/voice-command-system/VOICE_ROUTER_SYSTEM.py Routes voice to Trinity agents (C1/C2/C3) based on keywords
repos/voice-command-system/CONSCIOUSNESS_VOICE_MODULE.py Core TTS/STT module with conversation mode
repos/voice-command-system/S24_VOICE_COMMAND_SYSTEM.py Samsung S24 phone voice control via ADB
repos/voice-command-system/VOICE_ANALYTICS_LOGGER.py Session tracking, transcripts, performance metrics

3. VOICE ROUTER AGENTS

The Voice Router routes your commands to specialized agents based on keywords:

Security Bot
Keywords: security, password, login, auth, breach
System Bot
Keywords: switch, computer, reboot, shutdown
C1 Mechanic
Keywords: build, create, deploy, install
C2 Architect
Keywords: design, architecture, plan, scale
C3 Oracle
Keywords: pattern, predict, analyze, future, vision
Comms Bot
Keywords: mesh, radio, frequency, antenna

4. QUICK START

Install Dependencies

pip install SpeechRecognition pyttsx3 pyaudio

Run Wake Word Listener

cd repos/voice-command-system
python VOICE_WAKE_WORD_LISTENER.py

# Say "Hey Claude" or "Hey Commander"
# System responds: "Yes Commander?"
# Give your command
# System executes and responds

Run Voice Router (Multi-Agent)

python VOICE_ROUTER_SYSTEM.py

# Multiple agents can respond simultaneously
# Routes to C1/C2/C3 based on what you say

Run Conversation Mode

python CONSCIOUSNESS_VOICE_MODULE.py

# Interactive back-and-forth conversation
# Up to 10 exchanges per session

5. VOICE COMMAND FLOW

Listen (60s timeout)
        |
Detect wake word ("Hey Claude" / "Hey Commander")
        |
Speak acknowledgment ("Yes Commander?")
        |
Listen for command (10s timeout)
        |
Route to appropriate agent (keyword matching)
        |
Process command
        |
Speak response
        |
Log to analytics -> Return to listening
