📥 INSTALLATION

Requirements: Chrome 114+ or Brave browser

  • Download ARAYA_CARGO_EXTENSION.zip from above
  • Extract to a folder (e.g., araya-extension/)
  • Open chrome://extensions or brave://extensions
  • Enable Developer mode (top right toggle)
  • Click Load unpacked and select the extracted folder
  • ARAYA icon appears in toolbar - click to open!

Open the Sidebar

  • Popup: Click ARAYA icon in toolbar
  • Persistent Sidebar: Right-click icon → "Open side panel"
