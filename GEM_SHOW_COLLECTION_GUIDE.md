# Gem & Mineral Show Collection Display - User Guide

## Overview

The Gem & Mineral Show Collection Display is a dedicated platform for displaying collected items during gem and mineral shows. It allows users to showcase their collections, browse others' items, and initiate trade or sale requests with built-in notification support.

## Features

### 🌟 Collection Display
- **Display Toggle**: Mark any inventory item as "on display" at the show
- **Public Gallery**: Browse all collections from show attendees
- **Item Details**: View detailed information about displayed items
- **Owner Information**: See who owns each item with contact details

### 💬 Trade & Sale Requests
- **Trade Offers**: Propose item-for-item trades with other collectors
- **Purchase Requests**: Make offers to buy displayed items
- **Request Tracking**: Monitor status of all sent and received requests
- **Direct Contact**: Exchange contact information for follow-up

### 🔔 Notification System
- **Email Notifications**: Get notified via email when someone requests your items
- **SMS Notifications**: Optional SMS alerts (requires service integration)
- **In-App Notifications**: Real-time notification badge and history
- **Notification Preferences**: Customize how you want to be notified

### 🔗 Integration with Mineral Market
- **Shared Inventory**: Items from Mineral Market automatically available
- **User Accounts**: Use the same account across both platforms
- **PayPal Integration**: Complete purchases through existing payment system
- **Escrow Protection**: Broker-secured transactions for safety

## Getting Started

### Step 1: Connect Your Account

1. Visit https://barbrickdesign.github.io/gem-show-collection.html
2. Click "Connect Account" in the top right
3. If you don't have an account:
   - Click "Back to Market"
   - Create account in Mineral Market first
   - Return to Gem Show Collection

### Step 2: Add Items to Inventory

Items must first be added in the Mineral Market:

1. Go to [Mineral Market](mineralMarket.html)
2. Fill out "Add specimen" form:
   - Mineral name (e.g., Amethyst, Quartz)
   - Weight in grams
   - Classification (Cut Gem, Specimen, etc.)
   - Description and price
3. Click "+ Add to inventory"
4. Return to Gem Show Collection

Your inventory items will automatically appear in the "My Collection" section.

### Step 3: Display Items at Show

1. In "My Collection" section, find items you want to display
2. Click "✨ Display at Show" on any item
3. Item is now visible to all show attendees
4. Other users can send you trade/sale requests

### Step 4: Configure Notifications

1. Click your username in top right
2. Choose "Notification Settings"
3. Configure preferences:
   - ✅ Email notifications (enter your email)
   - ✅ SMS notifications (enter your phone number)
4. Click "Save Settings"

## Using the Platform

### Browsing Collections

**View All Displayed Items:**
1. Scroll to "Browse Show Collections" section
2. See all items other attendees are displaying
3. Click "View Details" for more information
4. Click "Request Trade/Buy" to initiate contact

**Filter Your Collection:**
- **All Items**: See your entire inventory
- **On Display**: Only items currently at show
- **Not Displayed**: Items in inventory but not shown

### Sending Requests

**To Request a Trade:**
1. Click "💬 Request Trade/Buy" on desired item
2. Select "Trade Offer" as request type
3. Choose item from your inventory to trade
4. Write message explaining your interest
5. Enter your contact information
6. Click "Send Request"

**To Request a Purchase:**
1. Click "💬 Request Trade/Buy" on desired item
2. Select "Purchase Request" as request type
3. Enter your offer price in USD
4. Write message with details
5. Enter your contact information
6. Click "Send Request"

### Managing Requests

**Incoming Requests:**
1. Go to "Trade & Sale Requests" section
2. Click "Incoming Requests" tab
3. Review each request:
   - See requester's name and contact
   - Read their message
   - View trade item or offer price
4. Respond with:
   - ✅ **Accept**: Approve the request
   - ❌ **Decline**: Reject the request

**Your Requests:**
1. Click "My Requests" tab
2. Track status of requests you've sent:
   - ⏳ **Pending**: Awaiting response
   - ✅ **Accepted**: Owner agreed
   - ❌ **Declined**: Owner declined

### Notifications

**Check Notifications:**
1. Click "🔔 Notifications" button
2. Badge shows unread count
3. View all notification history
4. Notifications automatically marked as read

**Notification Types:**
- New trade request received
- New purchase request received
- Your request was accepted
- Your request was declined

## Item Classifications

When adding items to inventory, choose the appropriate classification:

### **Cut Gemstones**
- Faceted, jewelry-ready finished products
- Highest value category
- Ready for immediate use in jewelry

### **Facet Clean Rough**
- High clarity rough material
- Suitable for professional faceting
- Good investment for cutters

### **Carving Rough**
- Raw material for carving/sculpture
- Suitable for artistic work
- Good for decorative pieces

### **Specimen Grade**
- Display quality specimens
- Aesthetic value for collectors
- Standard show display items

### **Museum Grade**
- Highest quality specimens
- Suitable for museum collections
- Premium pricing justified

### **Collector Grade**
- High quality for serious collectors
- Investment-grade pieces
- Strong market demand

### **Industrial/Practical Use**
- Materials for industrial applications
- Can be processed further
- Lower pricing category

## Transaction Flow

### For Sellers (Receiving Requests)

1. **Display Item**: Mark item as "on display" at show
2. **Receive Request**: Get notification via email/SMS
3. **Review Request**: Check requester's offer and message
4. **Respond**: Accept or decline the request
5. **Contact Buyer**: Use provided contact information
6. **Complete Transaction**: 
   - For trades: Exchange items directly at show
   - For sales: Use Mineral Market PayPal integration
7. **Update Display**: Remove sold items from display

### For Buyers (Sending Requests)

1. **Browse Collections**: Find items of interest
2. **Send Request**: Propose trade or purchase
3. **Await Response**: Seller notified automatically
4. **Get Notification**: Receive acceptance/decline notice
5. **Contact Seller**: Use provided contact information
6. **Complete Transaction**:
   - For trades: Meet at show to exchange
   - For purchases: Complete payment via PayPal
7. **Confirm Delivery**: Mark transaction complete

## Best Practices

### For Displaying Items

✅ **Do:**
- Take clear photos (when 3D support added)
- Write detailed, accurate descriptions
- Set reasonable prices based on market value
- Choose correct classification category
- Display your best specimens
- Respond to requests promptly

❌ **Don't:**
- Display items that are already sold
- Misrepresent quality or classification
- Ignore trade/sale requests
- Set unrealistic prices
- Display damaged items without disclosure

### For Requesting Items

✅ **Do:**
- Write thoughtful, respectful messages
- Make fair offers based on value
- Provide accurate contact information
- Respond if seller accepts
- Follow through on accepted requests
- Be prepared to negotiate

❌ **Don't:**
- Send spam or multiple duplicate requests
- Make lowball offers without explanation
- Provide fake contact information
- Ignore accepted requests
- Be pushy or demanding
- Harass other collectors

### Security & Safety

✅ **Meeting in Person:**
- Meet in public spaces at the show
- Bring a friend if large transaction
- Inspect items carefully before trade
- Get receipt for valuable items

✅ **Online Payments:**
- Use PayPal for buyer/seller protection
- Never send cash or wire transfers
- Document all communications
- Use escrow for high-value items

✅ **Contact Information:**
- Use platform messaging when possible
- Be cautious sharing personal info
- Verify identity before meeting
- Report suspicious activity

## Notification Details

### Email Notifications

When enabled, you'll receive emails for:
- New trade requests on your items
- New purchase requests on your items
- Responses to your requests (accepted/declined)
- Important updates to active requests

**Email Format:**
```
Subject: New Trade Request - [Item Name]
From: no-reply@barbrickdesign.com

Hello [Your Name],

[Requester Name] has sent you a trade request for your item:
[Item Name]

Request Type: Trade Offer / Purchase Request
Offered Item: [Trade item details] OR Offer Price: $[Amount]

Message:
[Requester's message]

Contact Information:
[Requester's contact]

To respond, visit: https://barbrickdesign.github.io/gem-show-collection.html

Thank you,
Gem & Mineral Show Team
```

### SMS Notifications

When enabled, you'll receive text messages for:
- New requests (brief alert)
- Request status changes
- Urgent updates

**SMS Format:**
```
Gem Show: New trade request from [Name] for [Item]. 
Check app to respond. Reply STOP to unsubscribe.
```

**Note:** SMS requires integration with Twilio or similar service. Currently simulated in demo.

### In-App Notifications

- Real-time badge on notification button
- Full notification history
- Mark as read functionality
- Persistent across sessions

## Integration with Mineral Market

### Shared Features

The Gem Show Collection shares data with Mineral Market:

- **User Accounts**: One account works on both platforms
- **Inventory**: Items sync automatically
- **Contact Info**: Use same PayPal/contact details
- **Transaction History**: Linked purchase records

### Workflow Example

1. **Add items** in Mineral Market inventory
2. **Display items** at Gem Show Collection
3. **Receive requests** through show platform
4. **Complete sales** using Market's PayPal system
5. **Update inventory** automatically when sold

### Data Storage

All data stored locally in browser using localStorage:

- **User profile**: Email, PayPal, display name
- **Inventory**: Items from Mineral Market
- **Display status**: Which items are shown
- **Requests**: Trade/sale request history
- **Notifications**: Notification archive
- **Settings**: Notification preferences

**Note:** Clear browser data will reset everything. Data is per-device.

## Troubleshooting

### Items Not Appearing

**Problem:** Inventory items don't show in My Collection

**Solutions:**
1. Ensure you're logged in with same account as Mineral Market
2. Refresh the page
3. Check items were added in Mineral Market first
4. Verify browser localStorage is enabled

### Notifications Not Working

**Problem:** Not receiving notification alerts

**Solutions:**
1. Click your username → Check notification settings
2. Verify email address is correct
3. Check spam/junk folder for emails
4. Ensure notifications are enabled in settings
5. SMS requires service integration (demo only currently)

### Display Toggle Not Working

**Problem:** Can't mark items as displayed

**Solutions:**
1. Ensure you're logged in
2. Verify item isn't already sold
3. Refresh page and try again
4. Check browser console for errors

### Request Not Sending

**Problem:** Trade/purchase request fails

**Solutions:**
1. Fill out all required fields
2. Ensure you're logged in
3. For trades: Have an item to offer
4. For purchases: Enter valid price
5. Check internet connection
