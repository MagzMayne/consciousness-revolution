🔧 Set Up Your Own Agent R
Fork the repo, configure your GitHub PAT, deploy to Railway — your supreme orchestrator awaits.
📋 Quick Setup Guide
  1. Fork github.com/barbrickdesign/barbrickdesign.github.io to your account
  2. Create a GitHub Personal Access Token with repo and workflow scopes
  3. Deploy the gateway/ folder to Railway.app (free tier works)
  4. Set the GATEWAY_TOKEN env var in Railway to a strong secret
  5. Open Settings in the full dashboard, paste your Railway URL and token, click Quick Connect
