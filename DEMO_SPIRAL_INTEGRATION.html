How to integrate user progress into ANY page

Step 1: Enter User ID

Step 2: See Integration Examples

Compact Widget

<div id="compactProfile"></div>
<script>
SpiralProfile.render('compactProfile', userId, {
compact: true
});
</script>

Stats Bar (Minimal)

<div id="statsBar"></div>
<script>
SpiralProfile.renderStatsBar('statsBar', userId);
</script>

Full Profile Widget

<div id="fullProfile"></div>
<script>
SpiralProfile.render('fullProfile', userId, {
compact: false,
showForges: true,
showOctave: true
});
</script>

Step 3: Use Spiral Engine API Directly

// Get user progress
const result = await SpiralEngine.getUserProgress(userId);
console.log(result.data);

// Add XP to a forge
await SpiralEngine.addXP(userId, 'reality', 500, 'quest_complete');

// Redeem cheat code
await SpiralEngine.redeemCheatCode(userId, 'PHOENIX');

// Initialize new user
await SpiralEngine.initializeUser(userId);

Quick Start: Add to Your Page

3 Lines of Code:

<!-- 1. Add scripts -->
<script src="js/spiral-engine.js"></script>
<script src="js/spiral-profile-widget.js"></script>

<!-- 2. Add container -->
<div id="userProgress"></div>

<!-- 3. Render widget -->
<script>
const userId = localStorage.getItem('userEmail') || 'demo-user';
SpiralProfile.render('userProgress', userId);
</script>
