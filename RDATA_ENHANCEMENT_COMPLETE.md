## 🎓 User Guide

### First Time Setup
1. Open `rdata.html` in browser
2. Wait 1-2 seconds for globe to load
3. Press **H** to see help and shortcuts
4. Press **S** to customize settings

### Basic Usage
- **Click** anywhere on globe to sample color and add marker
- **Drag** to rotate the view
- **Scroll** to zoom in/out
- **Press H** for help anytime
- **Press S** to adjust settings

### NASA API (Optional)
1. Get free API key from https://api.nasa.gov/
2. Enter in HUD panel (top right)
3. Key saves automatically
4. Click APOD or EONET buttons
5. Search API catalog

### Customization
Press **S** to open settings:
- Toggle auto-rotation
- Adjust rotation speed
- Show/hide clouds
- Show/hide atmosphere
- Adjust atmosphere glow
- Enable day/night cycle

## 💡 Tips for Users

1. **Save Your API Key** - Enter once, use forever
2. **Try Keyboard Shortcuts** - Much faster than mouse
3. **Customize Appearance** - Settings panel has everything
4. **Watch Markers Fade** - They disappear after 10 seconds
5. **Enable Day/Night** - See dynamic lighting
6. **Check History** - Left panel shows where you've been
7. **Reset View** - Press R if you get lost
8. **Clear Markers** - Press C to start fresh
