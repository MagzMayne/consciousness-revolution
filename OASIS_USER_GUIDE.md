## 🚀 Getting Started

### Opening OASIS
1. Navigate to `oasis.html` in your web browser

3. Choose your action:

## 📊 Understanding Your HUD

### Top-Left Panel - Player Status
- **Health Bar** (Pink gradient)
  - Shows current/max health
  - Changes color when low (red warning)
  - Animated pulse effect
- **XP Bar** (Purple gradient)
  - Shows progress to next level
  - Displays current level and XP needed
  - Fills up as you gain experience

### Top-Center - Score
- Real-time score display
- Increases with kills and achievements
- Formatted with thousands separators

### Top-Right - Location
- Shows your current sector coordinates
- Updates as you explore
- Format: "Sector X-Z"

## ⚔️ Combat System

### Fighting Enemies
- Enemies spawn randomly based on your level
- Two enemy types:
  - **Red enemies** - Melee attackers (close range)
  - **Blue enemies** - Ranged attackers (keep distance)
  
### Combat Mechanics
- Enemies have health bars above them
- Deal damage by clicking when in range
- Gain XP for each kill
- Higher level = stronger enemies & better rewards

### Attack Cooldown
- 0.5 second cooldown between attacks
- Cooldown is per player, not per enemy
- Visual feedback on successful hits

---

## 📈 Progression System

### Leveling Up
- Gain XP by defeating enemies
- Complete quests for bonus XP
- XP requirement increases each level
- Formula: Next Level = Current × 1.5

### Level Benefits
- **+20 Max Health** per level
- **+5 Attack Damage** per level
- **Full health restore** on level up
- Access to higher-tier areas
- Better loot drops

### Score System
- Base score from kills
- Bonus multiplier from quests
- Displayed in real-time
- Tracked for leaderboards (future)

## 🐛 Troubleshooting

### Game won't load
- Check browser console for errors
- Ensure WebGL is enabled
- Try incognito/private mode
- Clear browser cache

### Low FPS
- Close other browser tabs
- Reduce browser window size
- Disable browser extensions
- Check GPU drivers

### Wallet won't connect
- Install MetaMask extension
- Ensure wallet is unlocked
- Check network connection
- Use demo mode alternative

### Controls not working
- Click inside game window
- Check keyboard layout
- Disable conflicting extensions
- Try refreshing page

## 🎯 Tips & Strategies

### Beginner Tips
1. Complete tutorial quests first
2. Stay near structures for healing
3. Don't fight too many enemies at once
4. Collect crystals for power-ups
5. Explore different biomes gradually

### Advanced Strategies
1. **Kiting** - Attack while moving backwards
2. **Crowd control** - Separate enemy groups
3. **Resource management** - Save power-ups for bosses
4. **Map awareness** - Use minimap constantly
5. **Quest chaining** - Complete multiple simultaneously

### Combat Tips
- Watch enemy health bars
- Learn attack patterns
- Use terrain to your advantage
- Retreat to heal when needed
- Focus on weaker enemies first
