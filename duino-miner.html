Quick Setup Guide

  1. Create a Duino-Coin Account
    Visit wallet.duinocoin.com and register a free account. Save your username.
  2. Download the Official Miner
    Get the latest release from GitHub Releases or clone the repository: 
    git clone https://github.com/revoxhere/duino-coin.git
  3. For Arduino (USB Connection)
    • Install Arduino IDE
    • Upload the appropriate sketch from Arduino_Code/ folder
    • Run AVR_Miner.py on your PC
    • Enter your username and select the COM port
  4. For ESP8266/ESP32 (WiFi Standalone)
    • Upload ESP sketch with your WiFi credentials
    • Enter your Duino-Coin username in the code
    • Upload to device - it will mine automatically!
    • No PC required after setup
  5. Monitor Your Earnings
    Check your balance and mining stats at wallet.duinocoin.com
