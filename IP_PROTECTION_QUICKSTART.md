## Using the IP Protection Tool

### Protect New Files

When you add new source files to the repository, protect them:

```bash
node add-ip-protection-headers.js .
```

This will:
- Scan for new unprotected files
- Add IP protection headers
- Generate unique Patent Declaration IDs
- Update the patent registry

### Preview Changes (Dry Run)

To see what would be protected without making changes:

```bash
node add-ip-protection-headers.js . --dry-run
```

## FAQ

**Q: Will this break my code?**  
A: No. Headers are added as comments that don't affect execution.

**Q: Can I remove these headers?**  
A: No. Removing IP protection headers violates copyright and may result in legal action.

**Q: What if I'm a contributor?**  
A: Your contributions are protected too. See CONTRIBUTOR_GRANT_SYSTEM_GUIDE.md for revenue sharing details.
