## 🚀 Getting Started

### For Users

1. **Visit the Dashboard**
   ```
   https://barbrickdesign.github.io/agent-vetting-dashboard.html
   ```

2. **Register as Agent**
   - Provide name and email
   - Receive unique Agent ID
   - Start at Clearance Level 1

3. **Self-Assess Skills**
   - Browse 15 skill categories
   - Rate your proficiency (Novice to Master)
   - Provide evidence (projects, certifications)

4. **Make Contributions**
   - Contribute code to BarbrickDesign projects
   - Improve documentation
   - Help community members
   - Make financial donations

5. **Track Progress**
   - Compare yourself to Agent R
   - Watch your clearance level increase
   - Climb the leaderboard

### For Developers

1. **Include the Systems**
   ```html
   <script src="/agent-vetting-system.js"></script>
   <script src="/contribution-rewards-system.js"></script>
   <script src="/agent-hub-integration.js"></script>
   ```

2. **Initialize**
   ```javascript
   const hubIntegration = new AgentHubIntegration();
   ```

3. **Register Agent**
   ```javascript
   const agent = hubIntegration.registerAgent({
       name: 'John Doe',
       email: 'john@example.com'
   });
   ```

4. **Assess Skills**
   ```javascript
   hubIntegration.assessSkill(
       agentId,
       'AI_ENGINEERING',
       'LLM Fine-tuning',
       'EXPERT',
       {
           verified: true,
           yearsExperience: 5,
           projects: ['GPT Fine-tuning System']
       }
   );
   ```

5. **Log Contributions**
   ```javascript
   hubIntegration.logContribution(agentId, {
       type: 'code',
       description: 'Added new feature to payment system',
       verified: true
   });
   ```

6. **Log Donations**
   ```javascript
   hubIntegration.logDonation(agentId, {
       amount: 50.00,
       currency: 'USD',
       transactionId: 'TXN123456',
       verified: true
   });
   ```

## 💎 Value System

### Contribution Values

| Type | Base Value | Description |
|------|-----------|-------------|
| Code Feature | 100 | New feature implementation |
| Bug Fix | 50 | Bug resolution |
| Security Fix | 200 | Security vulnerability patch |
| Documentation | 25 | Doc improvements |
| Knowledge Base | 20 | KB article addition |
| Community Help | 10 | Helping other agents |

### Clearance Level Calculation

```
Clearance Level = Base (1) 
                + Value Contribution (max +50)
                + Skill Proficiency (max +30)
                + Verified Skills Bonus (max +20)
```

**Note:** Agent R's clearance level of 999 is reserved for the creator and cannot be reached by other agents.
