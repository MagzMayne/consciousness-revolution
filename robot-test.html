About the Robot Assistant

This is a test page for the ARAYA 3D Robot Assistant - a modern evolution of the classic office assistant (like Clippy), but way more advanced and consciousness-aware.

The robot uses Three.js for 3D rendering and maintains its state across page navigations using localStorage, just like the ARAYA chat memory system.

Features:

  • ✨ 3D animated robot with walking, idle, thinking, and speaking animations
  • 🚶 Autonomous wandering behavior when idle
  • 💾 State persistence across page reloads and navigation
  • 🔄 Syncs with ARAYA chat session ID
  • 🎨 ARAYA-themed colors (cyan, gold, purple)
  • 📱 Responsive and mobile-friendly

How It Works

State Management: The robot's position, animation state, and other properties are saved to localStorage every second and restored when you navigate between pages.

Session Sync: Uses the same session ID as ARAYA chat, so the robot is tied to your user identity.

Autonomous Behavior: After 3 seconds of inactivity, the robot will start wandering around the screen autonomously.

Event Integration: Responds to ARAYA chat events (message sent/received) with appropriate animations.
