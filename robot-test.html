How It Works

Identity: R3-D3 has a named identity and can be queried via getName() API.

Autonomous Editing: R3-D3 can edit pages through natural language using ARAYA Bridge and File Writer services.

Visual Design: Uses 🤖 emoji as head with a professional body design that matches the modern aesthetic.

State Management: The robot's position, animation state, editing permissions, and memory are saved to localStorage and persist across pages.

AI Brain: Tracks all pages in the repository, remembers which ones you've visited, and calculates your exploration score.

Tour System: Offers guided tours when you're new or when new features are available. Will walk you through key pages.

Autonomous Behavior: Follows your cursor, wanders when idle, and provides contextual help based on your location.

Interactive Communication: Uses speech bubbles to talk to you and can click buttons to navigate the site.
