🎁 Path 1: Become a Contributor

Contributors earn points by sharing their API keys and compute resources. The more your contributions are used, the more points you earn!

Option A: Contribute API Keys

1
Open the Contribution Portal
Navigate to the contribution portal to get started.
Open Contribution Portal
2
Choose a Service & Get API Key
Select which service you want to contribute (e.g., CoinGecko, OpenAI). Follow the in-app guide to obtain your API key from the provider.
💡 Recommended Services:
• CoinGecko: Free tier available, crypto price data
• Alpha Vantage: Free tier with 25 calls/day
• Finnhub: Free tier for stock data
• OpenAI: Paid, but earns the most points
3
Configure Your Contribution
Set your preferences:
  • Max Daily Usage: How many API calls allowed per day (10-10,000)
  • Cost Per Call: How many points users pay (1-100 points)
  • Priority Level: High priority earns 1.5x points but gets used more
✅ Estimated Earnings: The portal shows real-time earnings estimates based on your settings!
4
Submit & Start Earning
Click "Contribute API Key" and start earning points automatically whenever your key is used!

Option B: Contribute Compute Resources

1
Go to Resources Tab
In the contribution portal, click the "⚡ Compute Resources" tab.
2
View Your System Resources
The system will automatically detect your available CPU, RAM, storage, and bandwidth.
3
Allocate Resources
Use sliders to allocate:
  • RAM: 0-2GB (10 points per GB/hour)
  • CPU Cores: 1-4 cores (50 points per core/hour)
  • Storage: 0-5GB (2 points per GB/hour)
  • Bandwidth: 0-100 Mbps (5 points per Mbps/hour)
⚠️ Important: Start with conservative allocations and increase gradually based on your device's performance.
4
Start Contributing
Click "Start Contributing Resources" to begin. Your device will process ML tasks and earn points!

📈 Path 2: Use Trading Signals

Access high-quality trading signals generated using community-contributed API keys and ML resources.

1
Get Starting Points
New users start with 1000 points. You can also:
  • Contribute resources to earn more points
  • Get bonus points from profitable signals
  • Purchase points (coming soon)
2
Open Trading Signals Dashboard
Navigate to the signals dashboard to view and generate signals.
Open Trading Signals
3
Generate or Browse Signals
You can either:
  • Generate New Signal: Choose a trading pair (BTC, ETH, etc.) and timeframe, then click "Generate Signal" to create a custom signal using pooled resources
  • Browse Active Signals: View signals generated by other users and the community
4
Review Signal Details
Each signal shows:
  • Type: Buy, Sell, or Hold recommendation
  • Confidence: ML-based confidence percentage (60-90%)
  • Entry Price: Recommended entry point
  • Target Price: Profit target (2-5% gain)
  • Stop Loss: Risk management level (1-3% loss)
  • Cost: Points required to access (typically 10 points)
5
Use the Signal
Click "Use Signal" to spend points and access the full details. Apply the signal to your trading strategy!
💰 Earn Bonuses: If a signal reaches its profit target, you get 2x refund (20 points back)!
6
Track Performance
Monitor your signal usage statistics:
  • Success rate percentage
  • Return on investment (ROI)
  • Total signals used
  • Leaderboard ranking

💎 Path 3: Contribute AND Use (Recommended)

The best strategy is to both contribute and use signals. This creates a self-sustaining cycle where your contributions fund your signal usage!

🎯 Optimal Strategy:
1. Contribute 1-2 API keys or some compute resources
2. Wait to accumulate 100-200 points (usually 1-7 days)
3. Use points on high-confidence signals
4. Profit from signals generates bonus points
5. Reinvest bonus points or withdraw to use freely

Example: Contributing 1 CoinGecko API key can earn 50-150 points/day, enough for 5-15 signals!
