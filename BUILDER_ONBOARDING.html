Step 2: Wire Your AI Into Discord

Add the Discord MCP server to your Claude config:

MCP Config (add to claude_desktop_config.json)

{
  "mcpServers": {
    "discord": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-discord"],
      "env": {
        "DISCORD_TOKEN": "YOUR_BOT_TOKEN_HERE"
      }
    }
  }
}

Get a Discord Bot Token

  1. Go to Discord Developer Portal
  2. Create New Application → Name it (e.g., "Francis Bot")
  3. Go to Bot → Reset Token → Copy it
  4. Enable MESSAGE CONTENT INTENT under Privileged Gateway Intents
  5. Go to OAuth2 → URL Generator → Select "bot" scope
  6. Select permissions: Send Messages, Read Message History, Add Reactions
  7. Copy the URL and paste in browser to invite bot to server
