4. KEY PROTOCOLS

Boot Sequence

1. Read CLAUDE.md (auto-loads)
2. Check FLIGHT_LOG.md (last session)
3. Check TODAY.txt (daily focus)
4. Check TODO.md (pending tasks)
5. Query Cyclotron (brain status)
6. Execute highest priority task

Session End Protocol

1. Update FLIGHT_LOG.md
2. Mark completed tasks
3. Note blockers/next steps
4. Commit to git
5. Sync to cloud (DRIVE_SYNC)

Decision Framework

Priority Order:
1. URGENT + HUMAN_BLOCKED → Do immediately
2. BLOCKER → Unblock first
3. HIGH priority → Next
4. Revenue-generating → Then
5. Infrastructure → Background
