About this prototype
This is a minimal, in-browser sketch of the polymorphic architecture:
  • Each “brick” can render as splats, proxy mesh, or high-detail mesh.
  • Runtime chooses representation per frame based on distance, mode, and budget.
  • Overlay toggles show how LOD and polymorphism behave.
