  FIRST TIME SETUP  (run these once, in order)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  ┌─────────────────────────────────────────────────────┐
  │  Step 1 — Double-click:  SETUP.bat                  │
  │           Installs all Node.js and Python packages  │
  │           Takes 1-2 minutes. Run once.              │
  └─────────────────────────────────────────────────────┘

  ┌─────────────────────────────────────────────────────┐
  │  Step 2 — Double-click:  GET_KEYS.bat               │
  │           Sets up your API keys automatically       │
  └─────────────────────────────────────────────────────┘

  GET_KEYS.bat does the following for you:

    AUTO  →  Generates all secure keys (JWT, encryption, salts)
    AUTO  →  Scans your PC for any existing API keys
    AUTO  →  Sets all configuration defaults (ports, URLs, etc.)
    LOGIN →  Logs into YOUR GitHub account (device flow — no password)
              Opens browser → you enter a short code → done
    PULL  →  Reads your GitHub repo variables automatically
    PULL  →  Scans your GitHub Gists for a saved .env file
    SAVE  →  Offers to save your .env as a private GitHub Gist
              (makes future installs on any machine take 30 seconds)
    GUIDE →  Opens free API signup pages (Groq, Gemini, etc.)

  ┌─────────────────────────────────────────────────────┐
  │  Step 3 — Double-click:  START.bat                  │
  │           Browser opens at http://localhost:8080    │
  └─────────────────────────────────────────────────────┘

  STORING KEYS IN GITHUB (use on any machine — 30 second setup)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  The best way to move to a new machine or share between computers:

  BEST METHOD — Private Gist (GET_KEYS.bat does this automatically):
    1. Run GET_KEYS.bat on your current machine
    2. Log in to GitHub when prompted (enter short code in browser)
    3. Answer Y when asked to save as a private Gist
    4. On any new machine: run SETUP.bat → GET_KEYS.bat → log in → done

  ALTERNATIVE — GitHub Repo Variables (readable by the platform):
    Go to: Your GitHub repo → Settings → Secrets and variables
    → Actions → Variables tab → New repository variable
    Add keys like: GROQ_API_KEY, OPENAI_API_KEY, GOOGLE_GEMINI_API_KEY, etc.

  !! IMPORTANT: GitHub SECRETS cannot be read back by any tool !!
  !! Use Variables or a private Gist — not Secrets — for auto-pull  !!

  GET_KEYS.bat — ADVANCED OPTIONS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Open Command Prompt or PowerShell in the platform folder, then run:

  python GET_KEYS.py                    Full interactive setup
  python GET_KEYS.py --auto-only        Zero input (generate + scan only)
  python GET_KEYS.py --github-only      Pull from GitHub only
  python GET_KEYS.py --create-gist      Save .env to private GitHub Gist now
  python GET_KEYS.py --scan-only        Scan system only, no browser
  python GET_KEYS.py --no-github        Skip GitHub entirely
  python GET_KEYS.py --skip KEY1,KEY2   Skip specific keys

  Also available as a Node.js CLI:
  node github-key-manager.js            Full interactive flow
  node github-key-manager.js --pull     Pull keys from GitHub
  node github-key-manager.js --push     Save .env to Gist
  node github-key-manager.js --status   Show login and key status
  node github-key-manager.js --migrate  Copy .env keys to repo Variables
  node github-key-manager.js --logout   Clear stored GitHub token

  SETTING UP YOUR GITHUB REPO (recommended)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  For the platform to pull your keys automatically on any machine:

  1. Create a GitHub account if you don't have one: https://github.com/join
  2. Create a new repository (can be private)
  3. Note your username and repo name
  4. Run GET_KEYS.bat — it asks for these during setup
  5. Your keys are stored in a private Gist tied to your account
  6. On any new machine: SETUP.bat → GET_KEYS.bat → log in → all keys load

  Alternatively, add keys as repo Variables:
    Your repo → Settings → Secrets and variables → Actions → Variables tab
