## 💰 Understanding Values

### Node Sizes:
- **Small** = Lower value (<$500)
- **Medium** = Mid value ($500-$1,000)
- **Large** = High value (>$1,000)
- **Gold Glow** = Very high value (>$1,000)

### Layer Colors:
- **Gray "P"** = Peripheral (isolated, 0 connections)
- **Purple #** = Utility (helper, 1-3 connections)
- **Orange #** = Integration (feature, 4-8 connections)
- **Red #** = Core (critical, 9+ connections)

### Status Colors:
- **Green** = Complete
- **Blue** = Testing
- **Orange** = Incomplete

## ❓ Common Questions

### Q: Why is my repo worth $X?
**A:** Based on dev time ($75/hr), complexity, documentation, and connections.

### Q: What if a value seems wrong?
**A:** Check the node inspector for breakdown. Formula accounts for code metrics.

### Q: Can I adjust the hourly rate?
**A:** Yes, edit `DEV_RATE` variable in code (currently $75).

### Q: What's a "utility score"?
**A:** Connection importance. 0=isolated, 1-3=utility, 4-8=integration, 9+=core.

### Q: How do agents prioritize?
**A:** Outside-in (peripheral → utility → integration → core).

### Q: Where are logs stored?
**A:** Firebase Firestore (when authenticated) + browser localStorage.

## 🚨 Troubleshooting

### No nodes appear:
- Check internet connection
- Verify repository is public
- Look for console errors (F12)

### Values show $0:
- File may be empty or static HTML
- No functions detected
- Check inspector for details

### Agents don't deploy:
- Must scan repository first
- Check "📡 Scan Repository" completed
- See console for errors

### Firebase sync fails:
- Ensure signed in
- Check Firebase project config
- Verify internet connection
